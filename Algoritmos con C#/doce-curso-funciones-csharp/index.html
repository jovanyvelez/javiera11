1️⃣ ¿Qué es una función?

⏱️ 30 minutos · 📚 Conceptos fundamentales

🎬 Una analogía sencilla

Imagina una máquina de café:

  • ☕ Le pones agua y café molido (entradas)
  • ⚙️ La máquina hace su proceso interno (el código)
  • 🥤 Te entrega un café listo (salida)

Una función es exactamente eso: una mini-máquina dentro de tu programa que recibe datos, los procesa y devuelve un resultado.

📖 Definición técnica

Una función (también llamada método en C#) es un bloque de código que tiene un nombre y se puede ejecutar tantas veces como quieras. Sirve para:

  • ✅ Reutilizar código sin copiarlo y pegarlo
  • ✅ Organizar tu programa en piezas pequeñas
  • ✅ Probar cada parte por separado
  • ✅ Compartir trabajo con otros programadores

🧬 Anatomía de una función en C#

public static int Sumar(int a, int b)
{
    int resultado = a + b;
    return resultado;
}
public static

Modificadores: Le dicen al programa quién puede usar la función. Por ahora siempre escribiremos public static.

int

Tipo de retorno: Indica qué tipo de dato devuelve la función. int significa "número entero".

Sumar

Nombre: Cómo se llama tu función. Usa verbos en PascalCase (cada palabra empieza con mayúscula).

(int a, int b)

Parámetros: Los datos que recibe la función. Aquí pide dos números enteros.

{ ... }

Cuerpo: El código que se ejecuta dentro de la función.

return

Retorno: Devuelve un valor al lugar desde donde se llamó la función.

🎮 ¡Tu primera función completa!

Mira este programa completo. Léelo línea por línea:

using System;

class Programa
{
    // 👇 Aquí está la función Saludar
    public static void Saludar()
    {
        Console.WriteLine("¡Hola, mundo de C#!");
        Console.WriteLine("Soy una función ⚡");
    }

    // 👇 El método Main es el punto de entrada del programa
    public static void Main()
    {
        Saludar();   // ← Llamamos la función
        Saludar();   // ← La podemos llamar muchas veces
        Saludar();   // ← Esto es REUTILIZACIÓN
    }
}

📺 Salida en pantalla:

¡Hola, mundo de C#!
Soy una función ⚡
¡Hola, mundo de C#!
Soy una función ⚡
¡Hola, mundo de C#!
Soy una función ⚡

⚠️ Importante: void

Cuando una función no devuelve nada, usamos la palabra void (que significa "vacío" en inglés). Mira:

  • void Saludar() → No devuelve ningún valor, solo hace algo.
  • int Sumar(...) → Devuelve un número entero.

2️⃣ Parámetros: la puerta de entrada

⏱️ 40 minutos · 📚 Entradas a las funciones

🍕 Una analogía deliciosa

Piensa en una pizzería. Cuando pides una pizza, debes especificar:

  • 🍕 El tamaño (pequeña, mediana, grande)
  • 🧀 Los ingredientes (queso, jamón, champiñones)
  • 📍 Tu dirección

Esos detalles son los parámetros: información que la "función pizzería" necesita para hacer su trabajo.

📥 Funciones con un parámetro

public static void Saludar(string nombre)
{
    Console.WriteLine("¡Hola, " + nombre + "!");
}

public static void Main()
{
    Saludar("Camila");    // Imprime: ¡Hola, Camila!
    Saludar("Juan");      // Imprime: ¡Hola, Juan!
    Saludar("Profesor");  // Imprime: ¡Hola, Profesor!
}

👀 Fíjate: la función Saludar recibe un texto (string nombre) y lo usa dentro. Cada vez que la llamamos, le pasamos un nombre distinto.

📥📥 Funciones con varios parámetros

Puedes pedir todos los datos que necesites, separados por comas:

public static void MostrarFicha(string nombre, int edad, string ciudad)
{
    Console.WriteLine("Nombre: " + nombre);
    Console.WriteLine("Edad: " + edad);
    Console.WriteLine("Ciudad: " + ciudad);
}

public static void Main()
{
    MostrarFicha("Lucía", 16, "Bogotá");
}

📺 Salida:

Nombre: Lucía
Edad: 16
Ciudad: Bogotá

3️⃣ Retorno de valores: la salida mágica

⏱️ 35 minutos · 📚 Devolver resultados

🏧 Una analogía financiera

Un cajero automático funciona así:

  • 💳 Insertas la tarjeta y digitas el monto (parámetros)
  • ⚙️ El cajero verifica saldo y procesa (código interno)
  • 💵 Te entrega el dinero (valor de retorno)

El retorno es lo que la función "te entrega" después de hacer su trabajo.

📤 La palabra clave return

Para devolver un valor, usamos return seguido del valor que queremos entregar:

public static int Sumar(int a, int b)
{
    int resultado = a + b;
    return resultado;   // 👈 Aquí devolvemos el valor
}

public static void Main()
{
    int total = Sumar(7, 3);     // total vale 10
    Console.WriteLine(total);     // imprime: 10
}

🔑 Tres reglas de oro del return

  1. El tipo de lo que devuelves debe coincidir con el tipo declarado al inicio (int, string, etc.).
  2. Una vez ejecutado el return, la función termina inmediatamente. Lo que esté después no se ejecuta.
  3. Si tu función es void, no puede tener return con un valor (solo return; a secas, opcional).

🎁 Diferentes tipos de retorno

Retorno de un número:

public static int Cuadrado(int n)
{
    return n * n;
}
// Cuadrado(5)  →  25

Retorno de un texto:

public static string ObtenerSaludo(string nombre)
{
    return "¡Hola, " + nombre + "! Bienvenid@.";
}
// ObtenerSaludo("Ana")  →  "¡Hola, Ana! Bienvenid@."

Retorno booleano (verdadero o falso):

public static bool EsPar(int numero)
{
    if (numero % 2 == 0)
        return true;
    else
        return false;
}
// EsPar(4)   →  true
// EsPar(7)   →  false

💡 Tip pro

El ejemplo anterior se puede escribir de forma más corta así:

public static bool EsPar(int numero)
{
    return numero % 2 == 0;
}

¡Una sola línea! Porque numero % 2 == 0 ya es true o false por sí solo.

🔗 Encadenando funciones

Lo mejor del retorno es que puedes usar el resultado de una función como entrada de otra:

public static int Sumar(int a, int b) { return a + b; }
public static int Doble(int n)        { return n * 2;  }

public static void Main()
{
    int x = Doble(Sumar(3, 4));   // Sumar(3,4)=7  →  Doble(7)=14
    Console.WriteLine(x);          // imprime: 14
}

🚪 Retorno temprano (early return)

Puedes salir de una función antes con return. Es muy útil para casos especiales:

public static double Dividir(double a, double b)
{
    if (b == 0)
    {
        Console.WriteLine("⚠️ No se puede dividir por cero");
        return 0;       // Salida temprana
    }

    return a / b;       // División normal
}

4️⃣ Paso por valor vs por referencia

⏱️ 40 minutos · 📚 ¡El tema más importante!

📄 Una analogía clarísima

Imagina que le prestas tu cuaderno a un compañero:

  • 📋 Paso por valor: Le das una fotocopia. Él puede rayarla, doblarla, perderla… tu cuaderno original sigue intacto.
  • 📓 Paso por referencia: Le das el cuaderno original. Lo que él haga lo verás cuando te lo devuelva.

🟦 Paso por VALOR (lo normal)

Por defecto, C# pasa los parámetros por valor: hace una copia. Mira:

public static void Duplicar(int numero)
{
    numero = numero * 2;
    Console.WriteLine("Dentro de la función: " + numero);
}

public static void Main()
{
    int x = 5;
    Duplicar(x);
    Console.WriteLine("Fuera de la función: " + x);
}

📺 Salida:

Dentro de la función: 10
Fuera de la función: 5

👀 ¿Lo viste? La función modificó su copia interna, pero x en el Main sigue valiendo 5. Es como si le hubieras dado una fotocopia.

🟪 Paso por REFERENCIA (con ref)

Si quieres que la función modifique la variable original, usa ref en dos lugares: al declarar la función y al llamarla.

public static void Duplicar(ref int numero)
{
    numero = numero * 2;
}

public static void Main()
{
    int x = 5;
    Duplicar(ref x);    // 👈 Tienes que poner "ref" aquí también
    Console.WriteLine("x ahora vale: " + x);
}

📺 Salida:

x ahora vale: 10

🎉 Ahora sí, la variable original cambió. ¡Le diste el cuaderno original!

🟧 La palabra out (parámetros de salida)

Similar a ref, pero con una diferencia clave: out se usa cuando la función va a asignar un valor a la variable (la variable no necesita inicializarse antes).

public static void Dividir(int a, int b, out int cociente, out int residuo)
{
    cociente = a / b;
    residuo  = a % b;
}

public static void Main()
{
    int c, r;                       // No es necesario inicializar
    Dividir(17, 5, out c, out r);
    Console.WriteLine($"Cociente: {c}, Residuo: {r}");
}

📺 Salida:

Cociente: 3, Residuo: 2

💡 out es genial cuando una función necesita devolver más de un valor.

🎯 Ejemplo combinado: Intercambiar valores

El clásico problema: ¿cómo intercambias el valor de dos variables?

public static void Intercambiar(ref int x, ref int y)
{
    int temp = x;
    x = y;
    y = temp;
}

public static void Main()
{
    int a = 100, b = 200;
    Console.WriteLine($"Antes: a={a}, b={b}");

    Intercambiar(ref a, ref b);

    Console.WriteLine($"Después: a={a}, b={b}");
}

📺 Salida:

Antes: a=100, b=200
Después: a=200, b=100

🧪 Reto 2: Funciones de geometría

Área de un círculo:

public static double AreaCirculo(double radio)
{
    double PI = 3.14159;
    return PI * radio * radio;
}
// AreaCirculo(5)  →  78.53975

Perímetro de un rectángulo:

public static double PerimetroRectangulo(double ancho, double alto)
{
    return 2 * (ancho + alto);
}
// PerimetroRectangulo(4, 3)  →  14

Hipotenusa (Pitágoras):

public static double Hipotenusa(double catetoA, double catetoB)
{
    double suma = (catetoA * catetoA) + (catetoB * catetoB);
    return Math.Sqrt(suma);   // Math.Sqrt = raíz cuadrada
}
// Hipotenusa(3, 4)  →  5

💡 La clase Math

C# incluye una clase llamada Math llena de funciones matemáticas listas para usar:

  • Math.Sqrt(x) → raíz cuadrada
  • Math.Pow(x, y) → x elevado a y
  • Math.Abs(x) → valor absoluto
  • Math.PI → el valor de π
  • Math.Max(a, b) → el mayor de dos números
  • Math.Min(a, b) → el menor de dos números

🧪 Reto 3: Estadística básica

Promedio de tres notas:

public static double Promedio(double n1, double n2, double n3)
{
    return (n1 + n2 + n3) / 3;
}
// Promedio(4.0, 3.5, 4.8)  →  4.1

Calcular el porcentaje:

public static double Porcentaje(double parte, double total)
{
    return (parte / total) * 100;
}
// Porcentaje(15, 50)  →  30  (15 es el 30% de 50)

Factorial (un clásico):

public static long Factorial(int n)
{
    long resultado = 1;
    for (int i = 2; i <= n; i++)
    {
        resultado = resultado * i;
    }
    return resultado;
}
// Factorial(5)  →  120  (porque 1×2×3×4×5 = 120)

🏆 PROYECTO INTEGRADOR — Calculadora multifunción

Combina todo lo aprendido en un solo programa. Lee con atención este código completo:

using System;

class Calculadora
{
    public static double Sumar(double a, double b)        => a + b;
    public static double Restar(double a, double b)       => a - b;
    public static double Multiplicar(double a, double b)  => a * b;
    public static double Dividir(double a, double b)
    {
        if (b == 0) return 0;
        return a / b;
    }
    public static double Potencia(double baseN, double exp) => Math.Pow(baseN, exp);
    public static double Raiz(double n) => Math.Sqrt(n);

    public static void MostrarMenu()
    {
        Console.WriteLine("=== CALCULADORA ===");
        Console.WriteLine("1. Sumar");
        Console.WriteLine("2. Restar");
        Console.WriteLine("3. Multiplicar");
        Console.WriteLine("4. Dividir");
        Console.WriteLine("5. Potencia");
        Console.WriteLine("6. Raíz cuadrada");
        Console.WriteLine("0. Salir");
    }

    public static void Main()
    {
        int opcion;
        do
        {
            MostrarMenu();
            Console.Write("Elige una opción: ");
            opcion = int.Parse(Console.ReadLine());

            if (opcion == 0) break;

            Console.Write("Primer número: ");
            double a = double.Parse(Console.ReadLine());
            double b = 0;

            if (opcion != 6)
            {
                Console.Write("Segundo número: ");
                b = double.Parse(Console.ReadLine());
            }

            double resultado = 0;
            switch (opcion)
            {
                case 1: resultado = Sumar(a, b); break;
                case 2: resultado = Restar(a, b); break;
                case 3: resultado = Multiplicar(a, b); break;
                case 4: resultado = Dividir(a, b); break;
                case 5: resultado = Potencia(a, b); break;
                case 6: resultado = Raiz(a); break;
            }
            Console.WriteLine("Resultado: " + resultado + "\n");
        }
        while (opcion != 0);

        Console.WriteLine("¡Hasta luego! 👋");
    }
}

💡 Sintaxis nueva: => (lambda)

La flecha => es una forma corta de escribir funciones de una sola línea:

public static double Sumar(double a, double b) => a + b;

Es lo mismo que escribir:

public static double Sumar(double a, double b)
{
    return a + b;
}

6️⃣ 🧩 Algoritmos Modulares

⏱️ 35 minutos · 🏗️ Construir programas grandes con piezas pequeñas

🧱 La idea principal

"Divide y vencerás" es el lema. En vez de escribir un programa gigante de 200 líneas, lo partes en muchas funciones pequeñas que hacen UNA sola cosa cada una.

Ventajas:

  • 🧠 Fácil de entender (cada función cabe en tu cabeza)
  • 🔧 Fácil de arreglar (sabes dónde está el error)
  • ♻️ Fácil de reutilizar (las usas en otros proyectos)
  • 🤝 Fácil de trabajar en equipo (cada uno hace una función)

🎯 Regla de oro

Una función = una responsabilidad.

Si tu función "hace muchas cosas", probablemente debas dividirla en varias.

👀 Comparación: programa monolítico vs modular

❌ Mal ejemplo (todo en Main):

public static void Main()
{
    Console.Write("Nota 1: ");
    double n1 = double.Parse(Console.ReadLine());
    Console.Write("Nota 2: ");
    double n2 = double.Parse(Console.ReadLine());
    Console.Write("Nota 3: ");
    double n3 = double.Parse(Console.ReadLine());

    double prom = (n1 + n2 + n3) / 3;
    Console.WriteLine("Promedio: " + prom);

    if (prom >= 3.0)
        Console.WriteLine("APROBADO");
    else
        Console.WriteLine("REPROBADO");
}

✅ Buen ejemplo (modular):

public static double LeerNota(string mensaje)
{
    Console.Write(mensaje);
    return double.Parse(Console.ReadLine());
}

public static double CalcularPromedio(double n1, double n2, double n3)
{
    return (n1 + n2 + n3) / 3;
}

public static string Resultado(double promedio)
{
    return promedio >= 3.0 ? "APROBADO ✅" : "REPROBADO ❌";
}

public static void Main()
{
    double n1 = LeerNota("Nota 1: ");
    double n2 = LeerNota("Nota 2: ");
    double n3 = LeerNota("Nota 3: ");

    double prom = CalcularPromedio(n1, n2, n3);
    Console.WriteLine("Promedio: " + prom);
    Console.WriteLine(Resultado(prom));
}

¿Ves la diferencia? El segundo es como una receta clara: cada paso tiene un nombre que se entiende leyéndolo.

🏆 PROYECTO INTEGRADOR — Sistema de notas escolares

Vamos a construir un sistema completo paso a paso. Lee este código entero:

using System;

class SistemaNotas
{
    // ---- ENTRADA ----
    public static double LeerNota(string materia)
    {
        Console.Write($"Ingresa la nota de {materia} (0-5): ");
        return double.Parse(Console.ReadLine());
    }

    // ---- CÁLCULO ----
    public static double CalcularPromedio(double n1, double n2, double n3, double n4)
    {
        return (n1 + n2 + n3 + n4) / 4;
    }

    public static double CalcularMaxima(double n1, double n2, double n3, double n4)
    {
        double max = n1;
        if (n2 > max) max = n2;
        if (n3 > max) max = n3;
        if (n4 > max) max = n4;
        return max;
    }

    public static double CalcularMinima(double n1, double n2, double n3, double n4)
    {
        double min = n1;
        if (n2 < min) min = n2;
        if (n3 < min) min = n3;
        if (n4 < min) min = n4;
        return min;
    }

    // ---- DECISIÓN ----
    public static string EstadoEstudiante(double promedio)
    {
        if (promedio >= 4.5) return "🌟 EXCELENTE";
        if (promedio >= 4.0) return "🎉 SOBRESALIENTE";
        if (promedio >= 3.0) return "👍 APROBADO";
        return "📚 NECESITA REFUERZO";
    }

    // ---- SALIDA ----
    public static void MostrarReporte(string nombre, double prom, double max, double min, string estado)
    {
        Console.WriteLine("\n=== REPORTE DE " + nombre.ToUpper() + " ===");
        Console.WriteLine($"Promedio:    {prom:F2}");
        Console.WriteLine($"Nota máxima: {max:F2}");
        Console.WriteLine($"Nota mínima: {min:F2}");
        Console.WriteLine($"Estado:      {estado}");
        Console.WriteLine("===========================");
    }

    // ---- PROGRAMA PRINCIPAL ----
    public static void Main()
    {
        Console.Write("Nombre del estudiante: ");
        string nombre = Console.ReadLine();

        double mate = LeerNota("Matemáticas");
        double esp  = LeerNota("Español");
        double cien = LeerNota("Ciencias");
        double soc  = LeerNota("Sociales");

        double prom = CalcularPromedio(mate, esp, cien, soc);
        double max  = CalcularMaxima(mate, esp, cien, soc);
        double min  = CalcularMinima(mate, esp, cien, soc);
        string est  = EstadoEstudiante(prom);

        MostrarReporte(nombre, prom, max, min, est);
    }
}

💡 Observa la estructura

Las funciones están agrupadas por responsabilidad:

  • 📥 Entrada (LeerNota): recoge datos del usuario
  • 🧮 Cálculo (CalcularPromedio, CalcularMaxima, CalcularMinima): hace las cuentas
  • 🤔 Decisión (EstadoEstudiante): toma decisiones según los datos
  • 📺 Salida (MostrarReporte): muestra resultados

Este patrón se llama Entrada-Proceso-Salida (EPS) y es la base de casi todos los programas.

🚀 Desafío final del módulo

🏗️ Construye un convertidor de unidades modular.

Diseña un programa con estas funciones:

  • MetrosAPies(double m) → 1 metro = 3.281 pies
  • KilosALibras(double kg) → 1 kg = 2.205 libras
  • CelsiusAFahrenheit(double c)
  • MostrarMenu()
  • Main() que use un bucle para repetir hasta que el usuario quiera salir
using System;

class Convertidor
{
    public static double MetrosAPies(double m)        => m * 3.281;
    public static double KilosALibras(double kg)      => kg * 2.205;
    public static double CelsiusAFahrenheit(double c) => (c * 9.0 / 5.0) + 32;

    public static void MostrarMenu()
    {
        Console.WriteLine("\n=== CONVERTIDOR ===");
        Console.WriteLine("1. Metros → Pies");
        Console.WriteLine("2. Kilos → Libras");
        Console.WriteLine("3. Celsius → Fahrenheit");
        Console.WriteLine("0. Salir");
    }

    public static void Main()
    {
        int op;
        do
        {
            MostrarMenu();
            Console.Write("Opción: ");
            op = int.Parse(Console.ReadLine());
            if (op == 0) break;

            Console.Write("Valor a convertir: ");
            double v = double.Parse(Console.ReadLine());

            switch (op)
            {
                case 1: Console.WriteLine(MetrosAPies(v) + " pies"); break;
                case 2: Console.WriteLine(KilosALibras(v) + " libras"); break;
                case 3: Console.WriteLine(CelsiusAFahrenheit(v) + " °F"); break;
                default: Console.WriteLine("Opción inválida"); break;
            }
        }
        while (op != 0);

        Console.WriteLine("¡Adiós!");
    }
}
