💡 ¿Por qué los arreglos son tan importantes?

Un arreglo no es solo "muchas variables": es memoria contigua, es decir, los datos están pegados uno tras otro en la memoria del computador. Por eso el computador puede saltar directo a la posición 57. Esa misma idea (datos contiguos y acceso directo por posición) es la base de las bases de datos, de las imágenes, del audio y de los motores de los videojuegos. Tú hoy estás usando la misma idea que un motor de Fortnite.

📚 Arreglos unidimensionales: la fila de cajas

⏱️ 30 minutos · "Many boxes, one number"

🧠 ¿Qué es un arreglo?

Un arreglo es un bloque de variables del mismo tipo, numeradas y colocadas en fila. Cada casilla tiene un índice: su número de posición. Se declara con los corchetes [] después del tipo y su tamaño es fijo: si nace con 5 casillas, siempre tendrá 5 casillas.

Analogía: la fila de casilleros del colegio. Casillero 0, casillero 1, casillero 2… cada casillero guarda una cosa, todos guardan cosas del mismo tipo (o todos cuadernos, o todos los lápices). Si cambias de salón, cambias la fila completa: no puedes "añadir" un casillero nuevo en la mitad del año.

csharp — un arreglo y sus casillas 
// Un arreglo: cajas numeradas, una al lado de la otra
int[] notas = new int[5];      // 5 casillas, todas con 0

notas[0] = 85;
notas[1] = 90;
notas[2] = 78;

Console.WriteLine(notas[0]);       // 85
Console.WriteLine(notas[3]);       // 0 (nunca le escribimos)
Console.WriteLine($"Casillas: {notas.Length}");   // 5

// Las casillas que no escribas valen el valor "cero" del tipo
string[] nombres = new string[3];
Console.WriteLine(nombres[0] == null);   // True: en un string vacío es null

Qué hace: reserva 5 casillas de tipo int y deja que escribamos en cada una con su número. Por qué funciona: notas[0] no es una variable nueva: es "la casilla 0 del arreglo". Por eso solo funciona con números entre 0 y 4.

📌 Los índices empiezan en 0

Un arreglo de 5 casillas se numera 0, 1, 2, 3, 4. No existe la casilla 5. Tu ojo humano cuenta desde 1, el computador cuenta desde 0: es la diferencia entre "el primer estudiante" (índice 0) y "el último" (índice 4).

csharp-error — salirse del rango (error IndexOutOfRangeException) 
int[] notas = [85, 90, 78];

Console.WriteLine(notas[3]);   // ERROR: solo existen las casillas 0, 1 y 2
                               // Se lanza: IndexOutOfRangeException

✍️ Las cuatro formas de crear un arreglo

csharp — las cuatro formas de declarar un arreglo 
// 1. Con el tamaño: todas las casillas valen cero
int[] a = new int[3];

// 2. Con los valores desde el principio (forma clásica)
int[] b = new int[] { 10, 20, 30 };

// 3. Expresión de colección (C# 12 en adelante): la forma moderna
int[] c = [85, 90, 78];

// 4. Con var: C# deduce el tipo del contenido
var d = new int[] { 1, 2, 3 };

Console.WriteLine($"{a[0]} {b[0]} {c[0]} {d[0]}");
Console.WriteLine($"Tamaños: {a.Length}, {b.Length}, {c.Length}, {d.Length}");

// Ojo: var d = [1, 2, 3]; NO compila.
// Con una expresión de colección, C# necesita saber el tipo de destino:
// siempre escribe int[] d = [1, 2, 3];

💡 Truco: var y las expresiones de colección

Con var y un new todo bien: var a = new int[5];. Pero var d = [1, 2, 3]; no compila (error CS9176): con una expresión de colección, C# necesita saber de antemano el tipo donde va a guardar los datos. La solución es fácil: escribe el tipo, int[] d = [1, 2, 3];.

📏 Tamaño fijo vs. tamaño variable

csharp — arreglo rectangular y arreglo irregular (jagged) 
// Rectangular: todas las filas tienen EXACTAMENTE el mismo tamaño
int[,] tablero = new int[3, 4];
tablero[1, 2] = 7;

Console.WriteLine($"Tablero: {tablero.GetLength(0)} filas x {tablero.GetLength(1)} columnas");

// Irregular (jagged): cada fila puede tener un tamaño distinto
int[][] filas = new int[3][];
filas[0] = [1, 2, 3];
filas[1] = [4, 5];
filas[2] = [6];

Console.WriteLine($"Fila 1 tiene {filas[1].Length} números");
Console.WriteLine($"Fila 2 tiene {filas[2].Length} números");

💡 Truco: Length en vez de un número mágico

Nunca escribas for (int i = 0; i < 5; i++) si el arreglo tiene 5 casillas: si mañana le agregas una casilla, tu programa se rompe. Escribe siempre i < notas.Length. El computador ya sabe cuántas casillas hay: pregunta, no adivines.

🔎 Recorrer y buscar: leer todo el arreglo

⏱️ 30 minutos · "Un recorrido con y sin índice"

🧠 Recorrer es pasar por cada casilla

Un arreglo solo sirve si lo recorres. Existen dos formas clásicas: con for, cuando necesitas el índice (para saber en qué posición estás), y con foreach, cuando solo necesitas el valor de cada casilla.

csharp — recorrer con for y con foreach 
int[] notas = [85, 90, 78, 92, 60];

// Con for: NECESITO el índice (para saber la posición)
Console.WriteLine("Con for:");
for (int i = 0; i < notas.Length; i++)
{
    Console.WriteLine($"Posición {i}: {notas[i]}");
}

// Con foreach: solo necesito el valor de cada casilla
Console.WriteLine("Con foreach:");
foreach (int nota in notas)
{
    Console.WriteLine(nota);
}

Por qué funciona: notas.Length vale 5, así que el for recorre los índices 0, 1, 2, 3 y 4. En el foreach, C# te da una variable nueva (nota) que en cada vuelta toma el valor de la siguiente casilla. Ojo: el foreach es de solo lectura: si escribes nota = 0, el arreglo no cambia.

🎯 Buscar un elemento

csharp — buscar y devolver el índice (o -1) 
int[] notas = [85, 90, 78, 92, 60];
int objetivo = 92;

// El -1 es el código de "no lo encontré"
int indice = -1;

for (int i = 0; i < notas.Length; i++)
{
    if (notas[i] == objetivo)
    {
        indice = i;
        break;      // ya lo encontramos: no hace falta seguir buscando
    }
}

if (indice >= 0)
{
    Console.WriteLine($"Encontrado en la posición {indice}");
}
else
{
    Console.WriteLine("No está en el arreglo");
}

Por qué funciona: la bandera negativa (-1) se inicializa para el caso "no encontrado". Si el dato aparece, la bandera se reemplaza por su posición real. Es el mismo esquema del módulo 6: inicializar, buscar, decidir.

🧮 Calcular cosas con el arreglo

csharp — suma, promedio, mayor, menor y cuántos aprobaron 
int[] notas = [85, 90, 78, 92, 60];

{

    {

    }

    if (nota < menor)
    {
        menor = nota;

    {

}

Console.WriteLine($"Suma: {suma}");
Console.WriteLine($"Promedio: {promedio:F2}");

Ojo con un detalle: mayor y menor arrancan con notas[0] (no con 0), porque 0 siempre es menor que cualquier nota: si arrancaran en 0, el "menor" nunca se actualiza. Es la misma trampa de la variable candidata del módulo 6.

🟪 Matrices: arreglos de dos dimensiones

⏱️ 30 minutos · "Tablas con filas y columnas"

🧠 ¿Qué es una matriz?

Una matriz es un arreglo de dos dimensiones: tiene filas y columnas, y cada casilla se ubica con dos números: matriz[fila, columna]. Se declara con dos comas dentro de los corchetes: int[,].

Analogía: el tablero del juego de batalla naval o la tabla de parciales del salón: para encontrar una nota no basta con el número de la casilla, necesitas en qué fila y en qué columna está.

csharp — declarar e inicializar una matriz 
// Matriz rectangular: 3 filas x 4 columnas
int[,] tabla = new int[3, 4];

tabla[0, 0] = 10;
tabla[1, 2] = 25;

Console.WriteLine(tabla[0, 0]);   // 10
Console.WriteLine(tabla[1, 2]);   // 25

// Inicializarla con todos los valores de una sola vez
int[,] notaFinal = new int[,]
{
    { 3, 8, 4, 7 },
    { 2, 9, 5, 1 },
    { 6, 0, 8, 3 }
};

Console.WriteLine(notaFinal[2, 2]);                                  // 8
Console.WriteLine($"Filas: {notaFinal.GetLength(0)}, columnas: {notaFinal.GetLength(1)}");

Qué hace: reserva 3 filas de 4 columnas (12 casillas) y permite escribir en cada una con [fila, columna]. Por qué funciona: GetLength(0) devuelve el número de filas y GetLength(1) el de columnas. Ojo: un arreglo normal usa Length; una matriz usa GetLength(0) y GetLength(1).

📌 La regla de oro de la matriz

En matriz[f, c], la primera posición es siempre la fila y la segunda es la columna. Igual que en cualquier tablero: primero la fila, después la columna. Es la convención de C# (y de casi todos los lenguajes).

🔁 Recorrer una matriz: dos for anidados

csharp — llenar y mostrar una matriz 
int[,] tabla = new int[3, 3];
int contador = 1;

// Llenar la matriz: un for por cada dimensión
for (int i = 0; i < tabla.GetLength(0); i++)      // recorre las FILAS
{
    for (int j = 0; j < tabla.GetLength(1); j++)  // recorre las COLUMNAS
    {
        tabla[i, j] = contador;
        contador++;
    }
}

// Mostrarla
for (int i = 0; i < tabla.GetLength(0); i++)
{
    for (int j = 0; j < tabla.GetLength(1); j++)
    {
        Console.Write($"{tabla[i, j],4}");   // alineado en 4 columnas
    }
    Console.WriteLine();   // salto de línea al terminar cada fila
}

Por qué funciona: el for externo da la fila y el interno camina por las columnas de esa fila. Al terminar la fila, el Console.WriteLine() baja a la siguiente línea. Los dos for juntos recorren todas las casillas: en este caso, 3 x 3 = 9.

csharp — arreglo irregular (jagged): cada fila con su tamaño

int[][] filas = new int[3][];

filas[0] = [1, 2, 3];
filas[1] = [4, 5];
filas[2] = [6, 7, 8, 9];

💡 Truco: dibuja la matriz antes de escribir el código

En el cuaderno dibuja el tablero con los números de fila y columna arriba y a la izquierda. Si el índice no cabe en la matriz, el compilador te avisará. Y recuerda: GetLength(0) = filas, GetLength(1) = columnas. Si los mezclas, el error típico es "mi tablero sale con 4 filas y 3 columnas".

💡 ¿Sabías que…?

La palabra arreglo viene del español arreglar (poner en orden). Y en inglés, array, es un invento de John von Neumann en 1945, que inventó también la forma de guardar los números en el computador. C# 12 (2023) le puso el nombre moderno: expresión de colección, esa forma tan elegante de escribir int[] notas = [85, 90, 78];. Antes de C# 12 había que escribir new int[] { 85, 90, 78 } sí o sí.

🗃️ List<T> y colecciones: la lista que crece

⏱️ 25 minutos · "Cuando no sabes cuántos datos van a ser"

🧠 El problema del tamaño fijo

Un arreglo nace con un tamaño que no cambia. Pero casi siempre no sabes de antemano cuántos datos vas a tener: cuántos productos quiere el cliente, cuántos jugadores hay en la partida, cuántas notas se leen. Para eso existe List<T>: una lista que crece sola a medida que le agregas elementos.

Analogía: el arreglo es un casillero de tamaño fijo (una sola fila, siempre igual) y la lista es un bolsillo sin fondo: le metes hoja tras hoja y siempre cabe una más. Y con la diferencia clave: la lista te avisa cuántos elementos tiene con Count, mientras que el arreglo lo dice con Length.

csharp — los métodos de List<int> 
// La lista arranca vacía y crece cuando le hace falta
var notas = new List<int>();

notas.Add(85);                 // agregar uno
notas.AddRange([90, 78]);       // agregar varios de una vez

Console.WriteLine($"Cuántas hay: {notas.Count}");   // 3
Console.WriteLine($"La primera: {notas[0]}");        // 85
Console.WriteLine($"¿Está el 78? {notas.Contains(78)}");
Console.WriteLine($"Posición del 90: {notas.IndexOf(90)}");

notas.Insert(0, 60);   // insertar al principio
notas.Remove(90);      // quitar la PRIMERA coincidencia
notas.RemoveAt(0);     // quitar la posición 0

Console.WriteLine(string.Join(", ", notas));

notas.Sort();           // de menor a mayor
notas.Reverse();        // al revés
notas.Clear();          // vaciar la lista

Console.WriteLine($"Al final quedan: {notas.Count}");

Qué hace: la lista es un arreglo que sabe crecer. Por qué funciona: List<T> guarda los datos por dentro y, cuando necesita más espacio, pide uno nuevo y copia (por eso Add es un poquito más lenta que notas[i] = valor).

csharp — listas de texto y creación moderna 
// Una lista de nombres
var nombres = new List<string> { "Ana", "Beto", "Cami" };

Console.WriteLine($"¿Está Beto? {nombres.Contains("Beto")}");
Console.WriteLine($"Posición de Cami: {nombres.IndexOf("Cami")}");
Console.WriteLine($"Primero: {nombres[0]}");

// Expresión de colección (C# 12): la forma moderna de crearla
List<int> edades = [15, 16, 17];

Console.WriteLine($"Edades: {string.Join(" - ", edades)}");

// Y también sirve para leer datos que no conocemos de antemano
var productos = new List<string>();
Console.Write("Producto 1 (o \"salir\"): ");
string? entrada = Console.ReadLine();

while (entrada is not null && entrada != "salir")
{
    productos.Add(entrada);

    Console.Write("Producto (o \"salir\"): ");
    entrada = Console.ReadLine();
}

Console.WriteLine($"Productos: {productos.Count}");
Console.WriteLine(string.Join(", ", productos));

💡 Truco: var con listas

Escribe var notas = new List<int>(); y no List<int> notas = new List<int>();. Con var el tipo se deduce y tu código queda más corto. Igual funciona con los arreglos: var notas = new int[] { 85, 90, 78 };. Solo usa var cuando el tipo queda clarísimo a simple vista.

🧹 Ordenar y filtrar: del desorden al orden claro

⏱️ 30 minutos · "Sort, Where, Select"

🧠 Dos operaciones que cambian todo

Ordenar es acomodar los datos de menor a mayor (o al revés) para poder buscarlos rápido y entenderlos de un vistazo. Filtrar es quedarse solo con los datos que cumplen una condición. Son las dos operaciones que más se repiten en los programas del mundo real.

csharp — ordenar con Array.Sort y Array.Reverse 
int[] notas = [85, 90, 78, 92, 60];

Console.WriteLine($"Sin ordenar: {string.Join(", ", notas)}");

Array.Sort(notas);      // de menor a mayor (85, 78, 60, 90, 92)
Console.WriteLine($"Ordenado:   {string.Join(", ", notas)}");

Array.Reverse(notas);   // al revés: de mayor a menor
Console.WriteLine($"Invertido:  {string.Join(", ", notas)}");

// Ojo: Array.Sort modifica el arreglo original
// Si no quieres perderlo, primero haz una copia:
int[] copia = [85, 90, 78, 92, 60];
Array.Sort(copia);
Console.WriteLine($"El original sigue igual: {string.Join(", ", notas)}");
csharp — mayor, menor, suma y promedio con LINQ 
int[] notas = [85, 90, 78, 92, 60];
double[] decimales = [4.5, 3.0, 5.0];

Console.WriteLine($"Mayor: {notas.Max()}");
Console.WriteLine($"Menor: {notas.Min()}");
Console.WriteLine($"Suma: {notas.Sum()}");
Console.WriteLine($"Promedio: {notas.Average():F2}");

Console.WriteLine($"Promedio con decimales: {decimales.Average():F2}");
Console.WriteLine($"Suma con decimales: {decimales.Sum():F2}");

📌 Dato técnico: Max, Min, Sum y Average son de LINQ

No existen como métodos de la clase Array: son métodos de extensión de LINQ (vienen con using System.Linq;, que la plantilla ya incluye) y funcionan tanto con arreglos como con listas. Array.Sort, Array.Reverse, Array.IndexOf y Array.Exists, en cambio, sí son métodos propios de Array.

🫧 El ordenamiento burbuja, a mano

El Array.Sort es rapidísimo, pero no te enseña nada. El algoritmo burbuja sí: compara vecinos y los va "subiendo" como burbujas hasta que el arreglo queda ordenado. Sirve para entender por qué los algoritmos lentos existen.

csharp — ordenamiento burbuja (O(n²)) 
int[] numeros = [64, 34, 25, 12, 22, 11, 90];

// Pasadas: una por cada elemento menos el último
for (int i = 0; i < numeros.Length - 1; i++)
{
    // Comparaciones: hasta donde todavía no está ordenado
    for (int j = 0; j < numeros.Length - 1 - i; j++)
    {
        if (numeros[j] > numeros[j + 1])
        {
            // Intercambio: el grande baja, el pequeño sube
            int temporal = numeros[j];
            numeros[j] = numeros[j + 1];
            numeros[j + 1] = temporal;
        }
    }
}

Console.WriteLine(string.Join(", ", numeros));   // 11, 12, 22, 25, 34, 64, 90

Por qué funciona: en cada pasada, el número más grande queda al final de la parte sin ordenar. Por eso la pasada i ya no necesita comparar las últimas i casillas. El precio: hace n x n comparaciones (se dice O(n²)): con 10 datos son 100 comparaciones, con 1000 serían un millón. Por eso en la vida real usamos Array.Sort o List.Sort, que son mucho más listos.

🔗 LINQ: filtrar y transformar en una línea

csharp — Where, OrderBy y Select 
int[] notas = [85, 90, 78, 92, 60];
string[] estudiantes = ["Ana", "Beto", "Cami", "Dani", "Eva"];

// Where: quedarse solo con lo que cumple la condición
var aprobados = notas.Where(nota => nota >= 70).ToArray();
Console.WriteLine($"Aprobados: {string.Join(", ", aprobados)}");

// OrderBy: ordenar de menor a mayor (OrderByDescending hace el revés)
var ordenadas = notas.OrderBy(nota => nota).ToArray();
Console.WriteLine($"Ordenadas: {string.Join(", ", ordenadas)}");

// Select: transformar cada dato en algo nuevo
var conEstado = notas.Select(nota => nota >= 70 ? $"aprobó ({nota})" : $"falló ({nota})").ToArray();
Console.WriteLine(string.Join(" | ", conEstado));

// Los tres juntos, como una tubería
var resumen = estudiantes
    .Where((estudiante, i) => notas[i] >= 80)
    .Select((estudiante, i) => $"{estudiante}: {notas[i]}")
    .ToArray();

Console.WriteLine(string.Join(", ", resumen));

Qué hace: Where filtra, OrderBy ordena y Select transforma. Por qué funciona: cada una devuelve una colección nueva (por eso al final usas .ToArray() o .ToList() para guardarla). Encadenarlos es como una tubería: entra el arreglo, sale el resultado.

🗑️ "Borrar" un elemento de un arreglo

csharp — borrar con Array.IndexOf y Array.Copy 
int[] datos = [10, 20, 30, 40, 50];
int valorABorrar = 30;

int posicion = Array.IndexOf(datos, valorABorrar);

if (posicion >= 0)
{
    // Armamos un arreglo un poquito más corto
    int[] nuevo = new int[datos.Length - 1];

    // Copiamos lo que está ANTES del elemento
    Array.Copy(datos, 0, nuevo, 0, posicion);
    // Copiamos lo que está DESPUÉS del elemento
    Array.Copy(datos, posicion + 1, nuevo, posicion, datos.Length - posicion - 1);

    Console.WriteLine(string.Join(", ", nuevo));   // 10, 20, 40, 50
}
else
{
    Console.WriteLine("Ese valor no existe");
}

// Alternativa corta cuando solo quieres agregar espacio al final
int[] otro = [1, 2, 3];
Array.Resize(ref otro, 5);
otro[3] = 4;
otro[4] = 5;
Console.WriteLine(string.Join(", ", otro));   // 1, 2, 3, 4, 5

💡 Truco: si vas a borrar mucho, usa una lista

Quitar elementos de un arreglo es molesto (hay que copiar). En una lista es una línea: notas.Remove(30);. Por eso, si tu programa va a borrar mucho, nace como List<T> y al final lo conviertes a arreglo con notas.ToArray().

🛠️ Taller: tablero de calificaciones

⏱️ 45 minutos · "Arreglos, matrices y listas en un solo programa"

🛠️ Taller final Tablero de calificaciones del grado once

La coordinadora te pide un programa que junte dos cosas: una matriz con las notas de tres estudiantes en tres parciales, y un arreglo con las notas de todo el salón. Tu misión: construir TableroCalificaciones, un programa que use arreglos, matrices y una lista en el mismo archivo.

📋 Requisitos del taller

  1. Crea el proyecto: dotnet new console -n TableroCalificaciones y ábrelo con code ..
  2. La matriz: una matriz int[,] de 3 filas x 3 columnas (3 estudiantes, 3 parciales). Pide las 9 notas y valida cada una (un número de 0 a 100; si no es, vuelve a pedirla).
  3. Muestra el tablero en formato de tabla: nombre del estudiante, las 3 notas y su promedio (suma de sus 3 notas entre 3, con decimal).
  4. El arreglo: pide cuántos estudiantes hay y lee esa cantidad de notas en un arreglo int[].
  5. Con un recorrido del arreglo calcula: total, promedio general, mayor nota y menor nota.
  6. La búsqueda: pide una nota y usa Array.IndexOf para decir en qué posición está (o que no aparece).
  7. La lista: guarda en una List<int> todas las notas aprobadas (mayores o iguales a 60), ordénalas con Sort() y muéstralas.
  8. Al final muestra un resumen con todos los resultados. Usa interpolación y :F2 en los decimales.

💡 Cuidado con el menor

Las notas van de 0 a 100, así que el menor debe iniciar en 100 (el peor caso posible). Si lo inicias en 0, nunca va a cambiar y tu programa dirá que la menor nota es 0 aunque todos sacaran 80. Y recuerda: si el usuario dice que hay 0 estudiantes, no divides: revisa con un if (n > 0) antes de calcular el promedio.

csharp — solución del taller 
// =============================================
// TABLERO DE CALIFICACIONES DEL GRADO ONCE
// Matriz + Arreglo + Lista
// =============================================
Console.WriteLine("=== TABLERO DE CALIFICACIONES ===");

// ---------- 1. LA MATRIZ: 3 estudiantes x 3 parciales ----------
string[] estudiantes = ["Ana", "Beto", "Cami"];
int[,] parciales = new int[3, 3];
decimal[] promedios = new decimal[3];

for (int f = 0; f < parciales.GetLength(0); f++)
{
    decimal acumulado = 0m;

    for (int c = 0; c < parciales.GetLength(1); c++)
    {
        int nota = 0;
        bool notaValida = false;

        while (!notaValida)
        {
            Console.Write($"Nota de {estudiantes[f]} (parcial {c + 1}): ");
            int entrada = 0;

            if (int.TryParse(Console.ReadLine(), out entrada) && entrada >= 0 && entrada <= 100)
            {
                nota = entrada;
                notaValida = true;
            }
            else
            {
                Console.WriteLine("Nota inválida: debe ser un número de 0 a 100.");
            }
        }

        parciales[f, c] = nota;
        acumulado += nota;
    }

    promedios[f] = acumulado / parciales.GetLength(1);
}

// ---------- Mostrar el tablero ----------
Console.WriteLine();
Console.WriteLine($"{"Estudiante",-12}{"P1",6}{"P2",6}{"P3",6}{"Promedio",10}");

for (int f = 0; f < parciales.GetLength(0); f++)
{
    Console.Write($"{estudiantes[f],-12}");
    for (int c = 0; c < parciales.GetLength(1); c++)
    {
        Console.Write($"{parciales[f, c],6}");
    }
    Console.WriteLine($"{promedios[f],10:F2}");
}

// ---------- 2. EL ARREGLO CON TODAS LAS NOTAS DEL SALÓN ----------
Console.WriteLine();
Console.Write("¿Cuántos estudiantes hay en el salón? ");
int n = int.Parse(Console.ReadLine() ?? "0");
int[] notas = new int[n];

int suma = 0;        // ACUMULADOR
int mayor = 0;        // variable candidata
int menor = 100;      // variable candidata

for (int i = 0; i < n; i++)
{
    int nota = 0;
    bool notaValida = false;

    while (!notaValida)
    {
        Console.Write($"Nota {i + 1}: ");
        int entrada = 0;

        if (int.TryParse(Console.ReadLine(), out entrada) && entrada >= 0 && entrada <= 100)
        {
            nota = entrada;
            notaValida = true;
        }
        else
        {
            Console.WriteLine("Nota inválida: debe ser un número de 0 a 100.");
        }
    }

    notas[i] = nota;
    suma += nota;

    if (nota > mayor)
    {
        mayor = nota;
    }

    if (nota < menor)
    {
        menor = nota;
    }
}

// ---------- 3. LA BÚSQUEDA ----------
Console.Write("¿Qué nota quieres buscar? ");
int objetivo = int.Parse(Console.ReadLine() ?? "0");
int posicion = Array.IndexOf(notas, objetivo);

// ---------- 4. LA LISTA DE APROBADOS ----------
List<int> aprobados = new List<int>();

foreach (int nota in notas)
{
    if (nota >= 60)
    {
        aprobados.Add(nota);
    }
}

aprobados.Sort();

// ---------- 5. EL RESUMEN ----------
Console.WriteLine();
Console.WriteLine("=== RESUMEN DEL SALÓN ===");

if (n > 0)
{
    decimal promedioGeneral = (decimal)suma / n;
    Console.WriteLine($"Notas leídas:      {n}");
    Console.WriteLine($"Total:             {suma}");
    Console.WriteLine($"Promedio general:  {promedioGeneral:F2}");
    Console.WriteLine($"Mayor nota:        {mayor}");
    Console.WriteLine($"Menor nota:        {menor}");
}
else
{
    Console.WriteLine("No se leyeron notas: no hay nada que promediar.");
}

if (posicion >= 0)
{
    Console.WriteLine($"La nota {objetivo} está en la posición {posicion}.");
}
else
{
    Console.WriteLine($"La nota {objetivo} no aparece en la lista.");
}

Console.WriteLine($"Notas aprobadas ({aprobados.Count}): {string.Join(", ", aprobados)}");

  • La matriz es de 3 filas x 3 columnas y el tablero se muestra completo (las 9 casillas).
  • Los promedios por estudiante salen en decimal con :F2.
  • El arreglo se llena con exactamente los datos que pidió el usuario.
  • Si el usuario escribe letras o una nota fuera de 0 a 100, el programa vuelve a pedir el dato.
