🧠 ¿Qué es un lenguaje de programación?

⏱️ 30 minutos · "El idioma que habla con el computador"

🧠 La definición que sí sirve

Un lenguaje de programación es un lenguaje formal (con reglas estrictas) para escribir instrucciones que el computador ejecuta. Cada lenguaje tiene su estructura (cómo se escriben las cosas) y sus funciones (las piezas que hacen el trabajo). C# es uno de esos lenguajes: hoy lo vas a ver completo en un solo archivo.

🏗️ La estructura de todo programa

🎤

Entrada

Los datos que recibe el programa: lo que el usuario escribe con el teclado o lo que viene de un archivo.

⚙️

Proceso

Las operaciones: sumar, comparar, contar, decidir. Aquí viven las funciones.

📤

Salida

El resultado que se muestra: por pantalla, en un archivo o en otro programa.

csharp — entrada, proceso y salida 
// ENTRADA: el usuario escribe su nombre
Console.Write("Escribe tu nombre: ");
string nombre = Console.ReadLine() ?? "";

// PROCESO: una función que transforma el texto
string saludo = GenerarSaludo(nombre);

// SALIDA: el resultado
Console.WriteLine(saludo);

// Una FUNCIÓN: recibe un dato, devuelve un resultado
static string GenerarSaludo(string nombre)
{
    return $"Hola, {nombre}! Bienvenido a C#.";
}

💡 Función = nombre + parámetros + retorno

Acabas de usar tu primera función: GenerarSaludo. Recibe un parámetro de entrada (nombre), hace un proceso y devuelve un valor (return). Toda la clase 8 está dedicada a esto: funciones con parámetros, retorno, paso por valor y por referencia.

🖥️ Visual Studio Code + C# Dev Kit

⏱️ 35 minutos · "El editor donde vive tu código"

🧠 Editor vs. IDE

Un editor de texto (como el Bloc de notas) solo escribe letras. Un IDE (Integrated Development Environment) además entiende tu código: te autocompleta, te marca errores mientras escribes, te deja ejecutar con un botón y depurar línea por línea. Visual Studio Code nació como editor, pero con la extensión oficial de C# se convierte en un IDE completo.

🧩 ¿Qué es "C# Dev Kit"?

🔌 C# extension

El motor del lenguaje: IntelliSense, navegación, refactorización y diagnósticos. La publica Microsoft y se mantiene por separado.

🧰 C# Dev Kit

La capa de productividad: vista de solución, plantillas de proyecto, ejecución, depuración integrada y descubrimiento de pruebas.

🤖 IntelliCode (opcional)

Sugerencias de código potenciadas por IA. Se instala aparte y es muy recomendable, pero no es obligatoria.

📋 Paso a paso: deja VS Code listo

  1. Descarga VS Code desde code.visualstudio.com (Windows, macOS o Linux) e instálalo con las opciones por defecto.
  2. Abre la vista de Extensiones: haz clic en el ícono de cuadritos de la barra lateral o presiona Ctrl+Shift+X (en macOS: ⌘+⇧+X).
  3. Busca "C# Dev Kit" y pulsa Install. Fíjate que el editor de Microsoft dice Microsoft y no "unverified".
  4. Instala también "IntelliCode for C# Dev Kit" (opcional pero recomendado) y, si quieres F# o notebooks, el .NET Extension Pack.
  5. Acepta la sesión iniciada: C# Dev Kit pide iniciar sesión con una cuenta de Visual Studio para activar todas las funciones. Si el colegio tiene licenciamiento (Professional o Educator), usa el correo institucional.
  6. Abre el walkthrough: Ctrl+Shift+P → escribe Welcome: Open Walkthrough → Get Started with C# Dev Kit. Desde ahí puedes instalar el SDK de .NET en un clic.
📌

Versiones que usamos en el curso: Visual Studio Code 1.14x (la actual), C# Dev Kit (extensión oficial de Microsoft) y el SDK de .NET 10.0 con el lenguaje C# 14. .NET 10 es una versión Long Term Support: Microsoft le da mantenimiento hasta noviembre de 2028, así que es la versión estable que se debe aprender en el colegio (la .NET 11 que sale en noviembre de 2026 todavía es preview).

⚙️ El SDK de .NET 10 y tu primer proyecto

⏱️ 40 minutos · "Instalar, crear, ejecutar"

🧠 SDK, runtime y compilador

El SDK (Software Development Kit) es la caja de herramientas completa: incluye el compilador de C#, el runtime (lo que ejecuta el programa), las plantillas de proyecto y el comando dotnet. Instalar el SDK es como instalar "el programa completo"; instalar solo el runtime es como tener el reproductor de música sin las canciones.

📥 Instalar el SDK

  1. Entra a dotnet.microsoft.com/download/dotnet/10.0 y descarga el instalador de tu sistema operativo (Windows: .exe · macOS: .pkg · Linux: .deb/.tar.gz).
  2. Windows: abre el instalador y acepta las opciones por defecto. macOS: abre el .pkg. Linux: sudo apt install dotnet-sdk-10.0 (o el paquete de tu distribución).
  3. Alternativa sin salir de VS Code: en el walkthrough de C# Dev Kit, Set up your environment → Install .NET SDK → Install.
  4. Reinicia la terminal (cerrarla y abrirla otra vez) para que el sistema reconozca el comando dotnet.
🖥️ Verificar la instalaciónbash
$ dotnet --version
10.0.113
$ dotnet --list-sdks
10.0.113 [/usr/share/dotnet/sdk]
$ dotnet --info
Host (useful for support):
Version: 10.0.113

🦹 El villano: "dotnet no se reconoce como comando"

Ese mensaje significa que el SDK no está instalado o que la terminal no se reinició después de instalarlo. Solución: cierra todas las terminales (incluida la integrada de VS Code), abre una nueva y repite dotnet --version. Si sigue fallando, reinstala el SDK marcando la opción de agregarlo al PATH.

💡 Tres formas de crear el proyecto

  1. Desde la terminal (la que acabas de usar): dotnet new console -n MiApp.
  2. Desde VS Code: Ctrl+Shift+P → .NET: New Project → Console app → nombre.
  3. Desde el explorador: en la vista Explorer, botón Create .NET Project (aparece con C# Dev Kit instalado).

Las tres hacen exactamente lo mismo: crear la carpeta con los archivos del proyecto. Y siempre termina con dotnet run.

💡 ¿Sabías que…?

El nombre C# se pronuncia "C sharp" (C sostenido) y el símbolo # se elige porque es el "hash" de la música: C# es la versión afinada de C. C# fue creado por Anders Hejlsberg (el mismo que creó TypeScript y Turbo Pascal) y su primera versión salió en el año 2000 con .NET Framework 1.0. Hoy C# 14 es la versión que acompaña a .NET 10.

🐞 VS Code a fondo: terminal, ejecución y depuración

⏱️ 40 minutos · "Encuentra el error antes de que te encuentre"

🦹 El villano: el programa que no arranca

"Funcionaba y hoy no" es el drama clásico. La causa casi siempre es una de estas: un punto y coma faltante, una llave desbalanceada, un nombre escrito diferente en mayúsculas o minúsculas, o un error de compilación en una línea anterior. Para eso existe el depurador: te deja parar el programa en una línea exacta y ver qué hay en cada variable.

⌨️ La terminal integrada

Con Ctrl+` abres una terminal dentro de VS Code, en la carpeta del proyecto abierto. Todo lo que harías en el "Símbolo del sistema" de Windows o en la Terminal de macOS lo puedes hacer aquí.

🧰 Comandos que usarás siemprebash
$ dotnet run # compila y ejecuta
$ dotnet build # solo compila (para ver errores)
$ dotnet build --configuration Release # compila optimizado
$ dotnet clean # borra bin/ y obj/
$ dotnet new list # plantillas disponibles
$ dotnet run --project MiApp # ejecuta otro proyecto

🐞 Depurar paso a paso

  1. Escribe tu programa en Program.cs y guárdalo con Ctrl+S.
  2. Pon un punto de parada: haz clic en la barra vertical izquierda de la línea donde quieras parar. Aparece un círculo rojo.
  3. Pulsa F5. VS Code compila y arranca el programa; al llegar a esa línea, se pausa.
  4. Inspecciona: en el panel izquierdo (Variables) ves el valor de cada variable en ese instante. Pasa el mouse por encima de una variable y verás su valor en un tooltip.
  5. Avanza paso a paso: F10 = siguiente línea, F11 = entrar a la función, Shift+F11 = salir de la función, Shift+F5 = detener.
  6. Observa la terminal: abajo aparece la consola del programa. Si pides un dato con Console.ReadLine(), puedes escribirlo ahí mismo sin cambiar de ventana.

🏗️ ¿Cómo está hecho un programa en C#?

⏱️ 35 minutos · "Del archivo vacío a la primera clase"

🧠 Dos formas de escribir el mismo programa

Desde .NET 6, la plantilla de consola usa instrucciones de nivel superior (top-level statements): escribes las instrucciones directamente, sin envolverlas en una clase. C# las convierte por ti en un programa con una clase y un método Main. Antes se escribía todo a mano: namespace, class y static void Main. Las dos formas son válidas; la primera es la moderna y la que usa la plantilla de .NET 10.

csharp — forma moderna (top-level statements) 
// Este archivo es el programa completo.
// No hay namespace, no hay class, no hay Main: C# los pone por ti.

Console.WriteLine("Hola, grado once!");

int edad = 17;
Console.WriteLine($"Tu edad es {edad} años.");
csharp — forma clásica (namespace + class + Main) 
using System;   // habilita Console, Math, String...

namespace MiApp   // el espacio de nombres del proyecto
{
    class Program   // la clase del programa
    {
        static void Main(string[] args)   // el punto de entrada
        {
            Console.WriteLine("Hola, grado once!");
        }
    }
}
Pieza¿Qué hace?¿Se escribe hoy?
usingImporta espacios de nombres (como System) para no escribir el nombre completo.Ya no: ImplicitUsings lo hace por ti.
namespaceAgrupa tus clases bajo un "paquete" de nombres.No, si usas top-level statements.
class ProgramLa clase que contiene el programa.No, se genera sola.
static void MainEl punto de entrada: por aquí arranca todo.No, se genera solo.
Console.WriteLineEscribe un texto en la consola y salta a la línea.Sí, todos los días.
Console.WriteEscribe sin salto de línea (ideal para pedir datos).Sí, para menús.
Console.ReadLine()Lee una línea que escribe el usuario (vuelve como texto).Sí, para entrada.

🔠

Clases, métodos y propiedades: MiApp, CalcularPromedio, NombreCompleto.

🔡

camelCase

_camelCase

💡 Detalle moderno: la interpolación de strings

Fíjate en $"Tu edad es {edad} años.". El signo $ delante de las comillas convierte el texto en una cadena interpolada: dentro de las llaves { } puedes escribir cualquier expresión de C# (una variable, una suma, una llamada a función). Es la forma moderna de concatenar; la vieja era "Tu edad es " + edad + " años.".

csharp — un programa completo que ya compila 
// Ficha del estudiante
Console.WriteLine("=== FICHA DEL ESTUDIANTE ===");

Console.Write("Nombre: ");
string nombre = Console.ReadLine() ?? "";

Console.Write("Edad: ");
int edad = int.Parse(Console.ReadLine() ?? "0");

Console.WriteLine($"Nombre: {nombre}");
Console.WriteLine($"Edad: {edad}");
Console.WriteLine(edad >= 18 ? "Es mayor de edad" : "Es menor de edad");

🦹 Ojo con int.Parse

Si el usuario escribe "hola" en lugar de un número, int.Parse lanza una excepción y el programa se cae con un error rojo. En la clase 9 aprenderemos a usar int.TryParse, que pregunta "¿es un número?" y devuelve true o false sin romperse. De momento, escribe números válidos para probar.

🛠️ Taller: tu ficha de estudiante en consola

⏱️ 40 minutos · "Aplica todo lo aprendido"

🛠️ Taller final La ficha del estudiante

El colegio necesita un programa que pida los datos de un estudiante y los muestre en un formato ordenado. Tu misión: construir FichaEstudiante, una aplicación de consola que funcione de principio a fin.

📋 Requisitos del taller

  1. Crea el proyecto: dotnet new console -n FichaEstudiante y ábrelo en VS Code (code .).
  2. El programa debe pedir: nombre (texto), edad (número), promedio (número decimal) y ciudad (texto).
  3. Muestra los datos con interpolación, uno por línea, con un título y una línea separadora.
  4. Si el promedio es >= 3.0 muestra "🎓 Aprobado"; si no, "📚 Debe repetir".
  5. Agrega un comentario al inicio del archivo explicando qué hace el programa.
  6. Ejecuta con dotnet run, pruébalo con datos reales y con un promedio bajo (2.1) para ver las dos ramas.
csharp — guía de estilo (no es la solución, es el molde) 
// ============================================
// FICHA DEL ESTUDIANTE
// Pide datos y los muestra en un formato ordenado.
// ============================================

Console.WriteLine("=== FICHA DEL ESTUDIANTE ===");

// 1. Entrada
Console.Write("Nombre: ");
string nombre = Console.ReadLine() ?? "";

Console.Write("Edad: ");
int edad = int.Parse(Console.ReadLine() ?? "0");

Console.Write("Promedio: ");
double promedio = double.Parse(Console.ReadLine() ?? "0");

// 2. Proceso (decisión)
string estado = promedio >= 3.0 ? "Aprobado" : "Debe repetir";

// 3. Salida
Console.WriteLine("------------------------------");
Console.WriteLine($"Nombre:   {nombre}");
Console.WriteLine($"Edad:     {edad}");
Console.WriteLine($"Promedio: {promedio:F2}");
Console.WriteLine($"Estado:   {estado}");
Console.WriteLine("------------------------------");

💡 ¿Tu salida se parece a esta?

{promedio:F2} es el formato numérico: muestra el doble con exactamente 2 decimales (3.5 → 3.50). Es un detalle de "presentation" que se nota en los trabajos finales.
