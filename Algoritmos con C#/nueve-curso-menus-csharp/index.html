🎛️ Diseñar un menú (en papel primero)

⏱️ 25 minutos · "Dibujar antes de programar"

🧠 ¿Qué es un menú?

Un menú es una lista de opciones numeradas que el programa le muestra al usuario. El usuario escribe el número de la opción que quiere, el programa ejecuta esa acción y vuelve a mostrar el menú. Tres piezas y ya tienes un programa de verdad: mostrar → leer → actuar. 🍽️

✏️ Paso 1: el dibujo en papel

Nunca programes un menú sin dibujarlo antes. En el cuaderno (o en un comentario al inicio del archivo) escribe exactamente lo que el usuario va a ver:

2. Calcular el IMC
3. Convertir temperatura
0. Salir

> 2
Peso (kg): 68.5
Altura (cm): 172
IMC: 23.15
csharp — la función que dibuja el menú 
// Una función = un pedazo del menú
static void MostrarMenu()
{
    Console.Clear();   // borra lo anterior para que el menú se vea limpio
    Console.WriteLine("========== MENÚ PRINCIPAL ==========");
    Console.WriteLine("1. Calcular el área de un rectángulo");
    Console.WriteLine("2. Calcular el IMC");
    Console.WriteLine("3. Convertir temperatura");
    Console.WriteLine("0. Salir");
    Console.WriteLine("=====================================");
}

MostrarMenu();
Console.Write("Elige una opción: ");

🔄 Paso 2: el flujo

Un menú es un ciclo. Se repite siempre el mismo camino:

1️⃣

Mostrar

Se dibuja el menú. Aquí se llama a MostrarMenu().

2️⃣

Leer

Se lee la opción con Console.ReadLine(). El usuario escribe un número.

3️⃣

Actuar

Un switch decide qué hacer según el número. Al final, se vuelve al paso 1.

💡 Truco: dibuja el menú en una función, no en el medio del programa

Cuando el menú está en MostrarMenu(), cambiar un texto es cambiar una línea, no buscarla entre 200. Además el programa principal queda corto y legible. La deuda técnica empieza cuando el mismo bloque de código aparece en tres sitios distintos. 🧹

🔁 while + switch: el esqueleto

⏱️ 30 minutos · "El ciclo que mantiene el menú vivo"

🧠 El esqueleto clásico de un menú

Todo menú de consola se arma con las mismas tres piezas: un while que repite, un switch que decide y una variable bandera (salir) que le dice al while "ya está". Es un esqueleto reutilizable: lo aprendes una vez y lo usas para siempre. 🍔

csharp — el esqueleto completo de un menú 
bool salir = false;   // la bandera: mientras sea false, el menú sigue

while (!salir)
{
    MostrarMenu();
    Console.Write("Elige una opción: ");
    string opcion = Console.ReadLine() ?? "";

    switch (opcion)
    {
        case "1":
            Console.WriteLine("Calculando el área...");
            break;      // sin break se cae al siguiente caso
        case "2":
            Console.WriteLine("Calculando el IMC...");
            break;
        case "3":
            Console.WriteLine("Convirtiendo temperatura...");
            break;
        case "0":
            salir = true;    // el while va a terminar
            Console.WriteLine("¡Hasta luego!");
            break;
        default:
            Console.WriteLine("Opción inválida. Escribe un número del menú.");
            break;
    }
}

static void MostrarMenu()
{
    Console.Clear();
    Console.WriteLine("========== MENÚ PRINCIPAL ==========");
    Console.WriteLine("1. Calcular el área de un rectángulo");
    Console.WriteLine("2. Calcular el IMC");
    Console.WriteLine("3. Convertir temperatura");
    Console.WriteLine("0. Salir");
    Console.WriteLine("=====================================");
}

🔢 La opción: ¿string o int?

Console.ReadLine() siempre devuelve texto. Si comparas con case "1" (con comillas) comparas texto; si comparas con case 1 comparas números. Lo mejor es convertir una sola vez con int.TryParse y trabajar con números el resto del programa.

csharp — de texto a número, y el `switch` moderno 
Console.Write("Opción: ");
string texto = Console.ReadLine() ?? "";

// Convertimos UNA vez y con seguridad
int opcion = -1;
if (int.TryParse(texto, out int valor))
    opcion = valor;

switch (opcion)
{
    case 1:
        Console.WriteLine("Área de un rectángulo");
        break;
    case 2:
        Console.WriteLine("Índice de masa corporal");
        break;
    case 0:
        Console.WriteLine("Saliendo del programa");
        break;
    default:
        Console.WriteLine($"La opción '{texto}' no existe");
        break;
}

// La versión moderna: `switch` como EXPRESIÓN (devuelve un valor)
string mensaje = opcion switch
{
    1 => "Área de un rectángulo",
    2 => "Índice de masa corporal",
    0 => "Saliendo del programa",
    _ => "Opción inválida"
};

Console.WriteLine(mensaje);
ElementoCómo se usa aquí¿Cuándo usarlo?
while (!salir)Repite el menú hasta que la bandera se active.Siempre: es el corazón del menú.
while (true)Repite para siempre: hay que romperlo con break.Solo si usas un break interno para salir.
switchUna case por opción del menú.Cuando las opciones son valores exactos.
defaultLo que pasa si el usuario escribe cualquier otra cosa.Siempre: es tu red de seguridad.
breakSale de ese case.Siempre al final de cada case, o se ejecutan todos juntos.

🦹 El villano: el menú infinito del que no se puede salir

Si usas while (true) y en el case "0" solo escribes break, el break solo sale del switch: el while sigue dando vueltas y el menú nunca se cierra. La salida correcta es activar la bandera (salir = true;) y hacer break. 🔁

💡 Truco: la bandera también puede ser un bool que le preguntas al final

Si prefieres no usar salir, puedes escribir while (true) y, al final de cada vuelta, preguntar if (!Continuar()) break;. Pero la bandera salir es más fácil de entender y de depurar: siempre sabes en qué parte del código se apaga el programa. 🚦

🧩 Modularizar: una función por opción

⏱️ 30 minutos · "El menú mandón y sus ayudantes"

🧠 El menú no hace el trabajo: lo pide

Un buen menú se limita a preguntar y delegar: cada opción del switch llama a una función que hace el trabajo. El programa principal queda corto y legible, y cada función se puede probar sola. 🧩

csharp — el programa modularizado completo 
// ============================================
// PROGRAMA PRINCIPAL: solo pregunta y delegan
// ============================================
bool salir = false;

while (!salir)
{
    MostrarMenu();
    Console.Write("Elige una opción: ");

    if (int.TryParse(Console.ReadLine(), out int opcion))
    {
        switch (opcion)
        {
            case 1:
                CalcularArea();
                break;
            case 2:
                CalcularIMC();
                break;
            case 3:
                ListarEstudiantes();
                break;
            case 4:
                BuscarEstudiante();
                break;
            case 0:
                Salir();
                salir = true;
                break;
            default:
                Console.WriteLine("Opción inválida.");
                break;
        }
    }
    else
    {
        Console.WriteLine("Debes escribir un número.");
    }
}

// ============================================
// LAS FUNCIONES: aquí vive el trabajo de verdad
// ============================================
static void MostrarMenu()
{
    Console.Clear();
    Console.WriteLine("1. Calcular el área");
    Console.WriteLine("2. Calcular el IMC");
    Console.WriteLine("3. Listar estudiantes");
    Console.WriteLine("4. Buscar estudiante");
    Console.WriteLine("0. Salir");
}

static void CalcularArea()
{
    Console.Write("Ancho: ");
    double ancho = double.Parse(Console.ReadLine() ?? "0");
    Console.Write("Alto: ");
    double alto = double.Parse(Console.ReadLine() ?? "0");

    Console.WriteLine($"Área: {ancho * alto:F2}");
}

static void CalcularIMC()
{
    Console.Write("Peso (kg): ");
    double peso = double.Parse(Console.ReadLine() ?? "0");
    Console.Write("Altura (cm): ");
    double altura = double.Parse(Console.ReadLine() ?? "0");

    double metros = altura / 100.0;
    Console.WriteLine($"IMC: {peso / (metros * metros):F2}");
}

static void ListarEstudiantes()
{
    Console.WriteLine("No hay estudiantes registrados todavía.");
}

static void BuscarEstudiante()
{
    Console.Write("Nombre: ");
    string nombre = Console.ReadLine() ?? "";

    Console.WriteLine($"Buscando a {nombre}...");
}

static void Salir()
{
    Console.WriteLine("¡Hasta luego!");
}

💡 ¿Qué tamaño tiene que tener una función?

La regla práctica: si la función no cabe en una pantalla o tienes que desplazarte para leerla, probablemente hay que partirla. Y si el nombre no explica lo que hace, hay que renombrarla: CalcularIMC sí dice algo, Proceso2 no. 📏

🛡️ Validar la entrada del usuario

⏱️ 30 minutos · "El usuario siempre gana: prepárate"

🧠 El usuario va a escribir basura (y va a hacerlo con cariño)

Si tu programa dice "escribe tu edad" y alguien escribe "dieisiete", tu programa se cae con un error rojo. Un programa bien hecho no se cae: pregunta de nuevo con un mensaje amigable hasta obtener un dato válido. Eso se llama validar la entrada. 🛡️

csharp-error — así se cae el programa (por eso NO lo uses) 
// ⚠️ ESTE CÓDIGO ESTÁ MAL A PROPÓSITO.
// Si el usuario escribe letras, el programa revienta con
// una excepción (FormatException) y se cierra.
Console.Write("Escribe tu edad: ");
int edad = int.Parse(Console.ReadLine() ?? "0");

Console.WriteLine($"Tu edad es {edad}");
csharp — la versión que no se cae: `int.TryParse` 
// TryParse PREGUNTA "¿esto es un número?" y devuelve true o false.
// Nunca lanza excepciones.
Console.Write("Escribe tu edad: ");
string texto = Console.ReadLine() ?? "";

if (int.TryParse(texto, out int edad))
    Console.WriteLine($"Tu edad es {edad}");
else
    Console.WriteLine("Eso no es un número. Intenta de nuevo.");
csharp — la función que repregunta hasta obtener un dato válido 
// Valida un número entero dentro de un rango
static int LeerEntero(string mensaje, int minimo, int maximo)
{
    while (true)
    {
        Console.Write(mensaje);
        string texto = Console.ReadLine() ?? "";

        if (int.TryParse(texto, out int valor) && valor >= minimo && valor <= maximo)
            return valor;

        Console.WriteLine($"Dato inválido. Escribe un número entre {minimo} y {maximo}.");
    }
}

// Valida una nota de 0 a 10
static double LeerNota(string mensaje)
{
    while (true)
    {
        Console.Write(mensaje);
        string texto = Console.ReadLine() ?? "";

        if (double.TryParse(texto, out double nota) && nota >= 0 && nota <= 10)
            return nota;

        Console.WriteLine("La nota debe estar entre 0 y 10.");
    }
}

int nota = LeerEntero("Nota (0 a 10): ", 0, 10);
int cantidad = LeerEntero("Cantidad de notas: ", 1, 20);
Console.WriteLine($"{nota} y {cantidad}");

🦹 El villano: leer dos veces la misma línea

Si escribes int.TryParse(Console.ReadLine(), out int n) y después Console.ReadLine() otra vez, la segunda lectura se queda vacía: el usuario ya había escrito. Nunca le pidas al usuario la misma información dos veces: léela una vez, guárdala en una variable y trabaja con esa variable. ♻️

💡 Truco: el mensaje de error también es parte del programa

Un error amigable dice qué pasó y qué hacer: "Dato inválido. Escribe un número entre 0 y 10." es mil veces mejor que "Error de formato". Y el while (true) con return dentro es el patrón universal para "repreguntar hasta que esté bien". 🔁

🏗️ Menú + arreglos: administrar datos de verdad

⏱️ 30 minutos · "Un menú que recuerda a quién registraste"

🧠 El menú que guarda datos

Hasta ahora tus menús hacían cálculos y se olvidaban. Un programa serio guarda: los estudiantes registrados, las ventas del día, los libros prestados. Para eso usas un arreglo o una lista, y el menú elige qué función trabaja con ella. 🗂️

csharp — menú que administra una lista de estudiantes 
// La lista vive FUERA del while: así no se borra al reiniciar el menú
List<string> estudiantes = [];
bool salir = false;

while (!salir)
{
    Console.Clear();
    Console.WriteLine("=== MENÚ DE ESTUDIANTES ===");
    Console.WriteLine("1. Registrar estudiante");
    Console.WriteLine("2. Listar estudiantes");
    Console.WriteLine("3. Buscar estudiante");
    Console.WriteLine("4. Eliminar estudiante");
    Console.WriteLine("0. Salir");
    Console.Write("Elige una opción: ");

    int opcion = int.TryParse(Console.ReadLine(), out int valor) ? valor : -1;

    switch (opcion)
    {
        case 1:
            RegistrarEstudiante(estudiantes);
            break;
        case 2:
            ListarEstudiantes(estudiantes);
            break;
        case 3:
            BuscarEstudiante(estudiantes);
            break;
        case 4:
            EliminarEstudiante(estudiantes);
            break;
        case 0:
            salir = true;
            Console.WriteLine("¡Chao!");
            break;
        default:
            Console.WriteLine("Opción inválida.");
            break;
    }
}

static void RegistrarEstudiante(List<string> lista)
{
    Console.Write("Nombre del estudiante: ");
    string nombre = Console.ReadLine() ?? "";

    if (nombre.Length == 0)
    {
        Console.WriteLine("El nombre no puede estar vacío.");
        return;
    }

    lista.Add(nombre);
    Console.WriteLine($"Estudiante registrado: {nombre}");
}

static void ListarEstudiantes(List<string> lista)
{
    if (lista.Count == 0)
    {
        Console.WriteLine("No hay estudiantes registrados.");
        return;
    }

    Console.WriteLine("--- LISTA DE ESTUDIANTES ---");
    for (int i = 0; i < lista.Count; i++)
        Console.WriteLine($"{i + 1}. {lista[i]}");
}

static void BuscarEstudiante(List<string> lista)
{
    Console.Write("Nombre a buscar: ");
    string busqueda = Console.ReadLine() ?? "";

    bool encontrado = false;
    foreach (string nombre in lista)
    {
        if (nombre.Contains(busqueda, StringComparison.OrdinalIgnoreCase))
        {
            Console.WriteLine($"Encontrado: {nombre}");
            encontrado = true;
        }
    }

    if (!encontrado)
        Console.WriteLine("No se encontró ese estudiante.");
}

static void EliminarEstudiante(List<string> lista)
{
    Console.Write("Nombre a eliminar: ");
    string busqueda = Console.ReadLine() ?? "";

    int indice = -1;
    for (int i = 0; i < lista.Count; i++)
    {
        if (lista[i].Equals(busqueda, StringComparison.OrdinalIgnoreCase))
        {
            indice = i;
            break;
        }
    }

    if (indice >= 0)
    {
        Console.WriteLine($"Se eliminó a {lista[indice]}.");
        lista.RemoveAt(indice);
    }
    else
    {
        Console.WriteLine("Ese estudiante no está en la lista.");
    }
}

🦹 El villano: la lista declarada dentro del while

Si escribes List<string> estudiantes = []; dentro del while, la lista se crea de cero en cada vuelta: registras a Ana, el menú vuelve a empezar y Ana desaparece. La lista (y cualquier dato que deba vivir) se declara fuera del ciclo. 🧷

💡 Truco: pásale la lista a las funciones, no la declares adentro

Cuando una función necesita la lista, la recibe como parámetro (ListarEstudiantes(List<string> lista)). Recuerda la Clase 8: las listas son tipos de referencia, así que la función trabaja sobre la misma lista del programa principal. Si le haces cambios, se ven afuera. 🔗

⏱️ 45 minutos · "Tu primera aplicación de consola de verdad"

🏆 Taller final Sistema de matrícula

El colegio necesita un programa para matricular estudiantes: registrar, listar, buscar, cambiar el grado, eliminar y ver promedios. Cada opción del menú va en su propia función, los datos se guardan en una lista y todas las entradas del usuario se validan. 🎓

📋 Requisitos del taller

  1. Crea el proyecto: dotnet new console -n MatriculaColegio y ábrelo con code ..
  2. El menú tiene 6 opciones (registrar, listar, buscar, cambiar grado, eliminar, ver promedio) más la opción 0 para salir.
  3. Cada opción llama a una función propia: RegistrarEstudiante, ListarEstudiantes, BuscarEstudiante, CambiarGrado, EliminarEstudiante y VerPromedio.
  4. Los datos se guardan en una lista declarada fuera del while, y las funciones la reciben como parámetro.
  5. Valida todo: el código no puede estar vacío, no puede repetirse y las notas van de 0 a 10 (usa TryParse).
  6. Usa un record para el estudiante (Codigo, Nombre, Grado, Notas) y aprovecha with para cambiar el grado sin romper nada.
  7. Muestra la lista numerada y el promedio de cada estudiante con :F2.
  8. Prueba el programa de punta a punta: registra dos estudiantes, búscalos, cámbiales el grado y elimina uno.

💡 Pista: el truco del with

Los records de C# traen un detalle muy útil: lista[i] = lista[i] with { Grado = nuevoGrado }; te crea una copia con un dato cambiado y la deja en la lista, sin tocar las notas. Es la forma moderna de "modificar" un registro inmutable. 🎁

csharp — solución del taller 
// ============================================
// SISTEMA DE MATRÍCULA DEL COLEGIO — solución
// ============================================

List<Estudiante> estudiantes = [];
bool salir = false;

while (!salir)
{
    Console.Clear();
    Console.WriteLine("===== SISTEMA DE MATRÍCULA =====");
    Console.WriteLine("1. Registrar estudiante");
    Console.WriteLine("2. Listar estudiantes");
    Console.WriteLine("3. Buscar estudiante");
    Console.WriteLine("4. Cambiar el grado");
    Console.WriteLine("5. Eliminar estudiante");
    Console.WriteLine("6. Promedio de un estudiante");
    Console.WriteLine("0. Salir");
    Console.Write("Elige una opción: ");

    int opcion = int.TryParse(Console.ReadLine(), out int valor) ? valor : -1;

    switch (opcion)
    {
        case 1:
            RegistrarEstudiante(estudiantes);
            break;
        case 2:
            ListarEstudiantes(estudiantes);
            break;
        case 3:
            BuscarEstudiante(estudiantes);
            break;
        case 4:
            CambiarGrado(estudiantes);
            break;
        case 5:
            EliminarEstudiante(estudiantes);
            break;
        case 6:
            VerPromedio(estudiantes);
            break;
        case 0:
            salir = true;
            Console.WriteLine("¡Hasta la próxima!");
            break;
        default:
            Console.WriteLine("Opción inválida. Escribe un número del 0 al 6.");
            break;
    }
}

// FUNCIONES
// ============================================
static void RegistrarEstudiante(List<Estudiante> lista)
{
    Console.Write("Código: ");
    string codigo = Console.ReadLine() ?? "";

    if (codigo.Length == 0)
    {
        Console.WriteLine("El código no puede estar vacío.");
        return;
    }

    foreach (Estudiante e in lista)
    {
        if (e.Codigo.Equals(codigo, StringComparison.OrdinalIgnoreCase))
        {
            Console.WriteLine("Ese código ya está registrado.");
            return;
        }
    }

    Console.Write("Nombre: ");
    string nombre = Console.ReadLine() ?? "";

    Console.Write("Grado (ej. 11A): ");
    string grado = Console.ReadLine() ?? "";

    List<double> notas = [];
    for (int i = 0; i < 3; i++)
        notas.Add(LeerNota($"Nota {i + 1}: "));

    lista.Add(new Estudiante(codigo, nombre, grado, notas));
    Console.WriteLine($"{nombre} quedó matriculado en {grado}.");
}

static void ListarEstudiantes(List<Estudiante> lista)
{
    if (lista.Count == 0)
    {
        Console.WriteLine("No hay estudiantes matriculados.");
        return;
    }

    Console.WriteLine("--- ESTUDIANTES MATRICULADOS ---");
    for (int i = 0; i < lista.Count; i++)
    {
        Estudiante e = lista[i];
        Console.WriteLine($"{i + 1}. {e.Codigo} | {e.Nombre} | {e.Grado} | Promedio: {CalcularPromedio(e.Notas):F2}");
    }
}

static void BuscarEstudiante(List<Estudiante> lista)
{
    Console.Write("Código a buscar: ");
    string codigo = Console.ReadLine() ?? "";

    foreach (Estudiante e in lista)
    {
        if (e.Codigo.Equals(codigo, StringComparison.OrdinalIgnoreCase))
        {
            Console.WriteLine($"Encontrado: {e.Nombre} - Grado {e.Grado}");
            return;
        }
    }

    Console.WriteLine("No hay nadie con ese código.");
}

static void CambiarGrado(List<Estudiante> lista)
{
    Console.Write("Código: ");
    string codigo = Console.ReadLine() ?? "";
    Console.Write("Nuevo grado: ");
    string grado = Console.ReadLine() ?? "";

    for (int i = 0; i < lista.Count; i++)
    {
        if (lista[i].Codigo.Equals(codigo, StringComparison.OrdinalIgnoreCase))
        {
            lista[i] = lista[i] with { Grado = grado };
            Console.WriteLine($"Grado actualizado a {grado}.");
            return;
        }
    }

    Console.WriteLine("No se encontró el estudiante.");
}

static void EliminarEstudiante(List<Estudiante> lista)
{
    Console.Write("Código a eliminar: ");
    string codigo = Console.ReadLine() ?? "";

    for (int i = 0; i < lista.Count; i++)
    {
        if (lista[i].Codigo.Equals(codigo, StringComparison.OrdinalIgnoreCase))
        {
            Console.WriteLine($"Se eliminó a {lista[i].Nombre}.");
            lista.RemoveAt(i);
            return;
        }
    }

    Console.WriteLine("Ese estudiante no está matriculado.");
}

static void VerPromedio(List<Estudiante> lista)
{
    Console.Write("Código: ");
    string codigo = Console.ReadLine() ?? "";

    foreach (Estudiante e in lista)
    {
        if (e.Codigo.Equals(codigo, StringComparison.OrdinalIgnoreCase))
        {
            Console.WriteLine($"{e.Nombre} tiene un promedio de {CalcularPromedio(e.Notas):F2}");
            return;
        }
    }

    Console.WriteLine("No se encontró el estudiante.");
}

static double CalcularPromedio(List<double> notas)
{
    if (notas.Count == 0)
        return 0;

    double suma = 0;
    foreach (double nota in notas)
        suma += nota;

    return suma / notas.Count;
}

static double LeerNota(string mensaje)
{
    while (true)
    {
        Console.Write(mensaje);
        string texto = Console.ReadLine() ?? "";

        if (double.TryParse(texto, out double nota) && nota >= 0 && nota <= 10)
            return nota;

        Console.WriteLine("La nota debe ser un número entre 0 y 10.");
    }
}

// El record se declara al final del archivo
record Estudiante(string Codigo, string Nombre, string Grado, List<double> Notas);

✅ Antes de entregar, verifica

  • El proyecto se llama MatriculaColegio y corre con dotnet run.
  • El menú tiene 6 opciones + la opción 0 para salir, y el default atiende lo inválido.
  • Cada opción llama a su propia función (y el while no hace el trabajo).
  • La lista está declarada fuera del while: los datos sobreviven al menú.
  • Ningún dato se pide con int.Parse o double.Parse: todo pasa por TryParse.
  • El código no puede estar vacío ni repetirse, y las notas se validan entre 0 y 10.
  • La salida es limpia: el menú se vuelve a dibujar con Console.Clear() y el programa despide con un mensaje.

🔄 Actividad en pareja — 6 minutos

Uno hace de usuario: ejecuta el programa del otro e intenta romperlo. Escribe letras donde pide un número, pide notas de 99, mete el mismo código dos veces, escribe 0 y "-" en la opción. El programador anota cada falla y la arregla frente al otro. Al final, intercambien roles. 🛠️
