💡 La idea: una hilera de cajones

↑ Eso es un arreglo de 30 notas. Una sola variable, 30 valores adentro, cada uno en su cajón numerado.

📚 La definición formal (pero amigable)

Un arreglo unidimensional (también llamado array o vector) es:

Una estructura de datos que guarda una cantidad fija de elementos del mismo tipo, organizados en posiciones numeradas (índices), accesibles mediante un número de posición.

Las palabras clave que tienes que grabar:

  • 📦 Cantidad fija: cuando creas un arreglo, decides cuántos cajones tiene, y eso no cambia.
  • 🎨 Mismo tipo: todos los elementos son del mismo tipo: todos int, todos string, todos double...
  • 🔢 Posiciones numeradas: cada cajón tiene un número (el índice) que lo identifica.
  • 🧭 Acceso por índice: para leer o escribir un valor, dices el número de cajón.

🆚 Sin arreglos vs. con arreglos

❌ Sin arreglos (30 variables):

double n01, n02, n03, n04, n05, n06, n07, n08, n09, n10,
       n11, n12, n13, n14, n15, n16, n17, n18, n19, n20,
       n21, n22, n23, n24, n25, n26, n27, n28, n29, n30;
// ¿Y el promedio? 🙃
double suma = n01 + n02 + n03 + /* ... 27 más ... */ + n30;
double prom = suma / 30;

✅ Con arreglos (¡mira qué diferencia!):

double[] notas = new double[30];
// ... (más adelante veremos cómo llenarlo) ...
double suma = 0;
for (int i = 0; i < notas.Length; i++)
{
    suma = suma + notas[i];
}
double promedio = suma / notas.Length;

👀 ¿Ves? El segundo programa funciona para 30, 300 o 3 millones de notas sin cambiar una sola línea. Esa es la magia de los arreglos. ✨

2️⃣ Tu primer arreglo en C#

⏱️ 30 minutos · 🛠️ Manos a la obra

📐 La sintaxis, paso a paso

Crear un arreglo en C# se hace en dos pasos: primero lo declaras (le dices al programa "voy a usar un arreglo"), después lo construyes (le dices "crea los cajones").

🪜 Paso 1: Declarar el arreglo

Para declarar un arreglo, escribe el tipo, seguido de [] (corchetes), el nombre y ;:

// Sintaxis general:
// tipo[] nombre;

int[]      notas;     // arreglo de números enteros
double[]   precios;   // arreglo de precios (con decimales)
string[]   nombres;   // arreglo de textos
bool[]     aprobado;  // arreglo de verdadero/falso

👀 Ojo: los corchetes [] van siempre pegados al tipo, no al nombre. Esto es importante en C#.

🪜 Paso 2: Construir el arreglo

Con la palabra new + el tipo + el tamaño entre corchetes:

// Sintaxis general:
// nombre = new tipo[tamaño];

notas    = new int[30];      // 30 cajones para enteros
precios  = new double[100];  // 100 cajones para decimales
nombres  = new string[5];    // 5 cajones para textos

Ahora puedes imaginarlo así:

📦 int[] notas = new int[5];

00
10
20
30
40

↑ El programa creó 5 cajones y los llenó con el valor por defecto de int: 0.

📝 Los dos pasos en uno

Lo más común es declarar y construir en la misma línea:

int[]    notas    = new int[5];
double[] precios  = new double[100];
string[] nombres  = new string[3];

💧 Valores por defecto (¡importante!)

Cuando creas un arreglo, C# lo llena automáticamente con el valor por defecto del tipo:

TipoValor por defectoEjemplo
int00, 0, 0, 0, 0
double0.00.0, 0.0, 0.0
boolfalsefalse, false, false
stringnull (texto vacío)null, null, null
char'\0' (carácter nulo)'\0', '\0', '\0'

⚠️ Trampa típica con string

Si creas string[] nombres = new string[3];, los tres cajones empiezan como null (nulo), no como "" (texto vacío). Si los concatenas con otro texto, te puede dar error. La solución: inicialízalos con "" o asígnales un valor antes de usarlos.

🎁 Atajo: declarar y dar valores de una vez

Si ya sabes qué valores tendrá tu arreglo, puedes crearlo así:

int[] notas = new int[] { 45, 50, 38, 42, 49 };
//         equivale a: ↑ tamaño implícito (5)

string[] colores = { "rojo", "azul", "verde" };
// ↑ la palabra 'new' es opcional cuando das valores

👀 Detalle importante: si usas esta forma, no pones el tamaño. El tamaño se infiere de la cantidad de valores.

📊 Tamaño fijo, pero se puede preguntar

Una vez creado, el tamaño no cambia. Pero siempre puedes preguntarlo con la propiedad Length:

int[] notas = new int[30];
Console.WriteLine(notas.Length);   // imprime: 30

string[] frutas = { "manzana", "pera", "uva" };
Console.WriteLine(frutas.Length);  // imprime: 3

💡 ¿Por qué importa Length?

Imagina que en un momento dado no recuerdas cuántos cajones tiene un arreglo. Length te lo dice. Y todavía más importante: lo vamos a usar todo el tiempo en los bucles for para recorrer todo el arreglo, sin importar su tamaño. Ya llegaremos a eso. 😉

3️⃣ Los índices: el GPS de los datos

⏱️ 30 minutos · 🔑 La clave para entrar a cada cajón

🗺️ El GPS de cada cajón

Ya tenemos los cajones. Ahora necesitamos una forma de decirle al programa cuál cajón queremos. Para eso existen los índices: los números que identifican cada posición.

🪜 La regla: empezamos en 0

En C# (y en casi todos los lenguajes de programación), los índices empiezan en 0, no en 1. Es como el piso 0 de un edificio: existe y es el primero.

📦 Arreglo de 5 elementos

0A
1B
2C
3D
4E

El primer cajón es el 0. El último es el 4 (no el 5).

🤔 ¿Por qué empiezan en 0?

Es una convención que viene del lenguaje C, muy viejo, y que casi todos los lenguajes copiaron. La idea es: el índice representa cuántos pasos hay que dar desde el principio para llegar al cajón. Para llegar al primero, das 0 pasos. Para llegar al segundo, das 1 paso. ¡Es algo así como contar separaciones! 🚶

Lo importante es que te acostumbres. Después de unas horas, ni lo notas. 😉

✍️ Asignar valores (escribir dentro de un cajón)

Para meter un valor en un cajón, usa el [] con el número del cajón a la izquierda del =:

int[] notas = new int[5];

notas[0] = 45;   // cajón 0 ahora vale 45
notas[1] = 50;   // cajón 1 ahora vale 50
notas[2] = 38;   // cajón 2 ahora vale 38
notas[3] = 42;   // cajón 3 ahora vale 42
notas[4] = 49;   // cajón 4 ahora vale 49

📖 Leer valores (sacar lo que hay en un cajón)

Para leer, usa el [] en una expresión, en una asignación o en un Console.WriteLine:

int[] notas = { 45, 50, 38, 42, 49 };

int primera = notas[0];          // primera vale 45
int ultima  = notas[4];          // ultima vale 49
int suma    = notas[0] + notas[1];  // 45 + 50 = 95

Console.WriteLine(notas[2]);     // imprime: 38
Console.WriteLine("La primera nota es: " + notas[0]);

⚠️ ¡Cuidado! Salirse del rango

El error más común al trabajar con arreglos: intentar acceder a un cajón que no existe. Esto se llama IndexOutOfRangeException y en C# el programa se cae.

int[] notas = new int[5];   // cajones del 0 al 4

Console.WriteLine(notas[5]);    // 💥 ERROR: no existe el cajón 5
Console.WriteLine(notas[10]);   // 💥 ERROR: no existe el cajón 10
Console.WriteLine(notas[-1]);   // 💥 ERROR: no existe el cajón -1

🛡️ Tres reglas de seguridad

  1. 🔢 Si el arreglo tiene N elementos, los índices válidos van de 0 a N - 1.
  2. 📏 N - 1 = arreglo.Length - 1, o sea, el último cajón.
  3. 🚫 Nunca uses índices negativos ni mayores o iguales al tamaño.

4️⃣ Recorrer con for y la propiedad Length

⏱️ 30 minutos · 🔁 El patrón más usado de los arreglos

🤔 El problema

Ya sabemos acceder a un cajón por su índice. Pero, ¿qué pasa si tenemos 100 cajones? ¿Vamos a escribir Console.WriteLine 100 veces? ¡Claro que no! Para eso existe el for.

🔁 El patrón clásico: recorrer un arreglo con for

La idea es simple: una variable (i) va tomando los valores 0, 1, 2, ... hasta el último índice, y en cada vuelta hacemos algo con el cajón arreglo[i].

// Patrón: recorrer un arreglo de principio a fin
for (int i = 0; i < arreglo.Length; i++)
{
    // 'i' va de 0 hasta arreglo.Length - 1
    Console.WriteLine(arreglo[i]);
}

🔍 Anatomía del for para arreglos

  • int i = 0; → empezamos en el primer cajón.
  • i < arreglo.Length; → seguimos mientras i sea menor que el tamaño.
  • i++ → pasamos al siguiente cajón.
  • arreglo[i] → accedemos al cajón actual.

👀 Ejemplo: mostrar todas las notas

int[] notas = { 45, 50, 38, 42, 49 };

for (int i = 0; i < notas.Length; i++)
{
    Console.WriteLine("Cajón " + i + ": " + notas[i]);
}

📺 Salida:

Cajón 0: 45
Cajón 1: 50
Cajón 2: 38
Cajón 3: 42
Cajón 4: 49

🧮 Ejemplo: sumar todas las notas

El mismo patrón, pero esta vez acumulamos valores en una variable:

int[] notas = { 45, 50, 38, 42, 49 };
int suma = 0;

for (int i = 0; i < notas.Length; i++)
{
    suma = suma + notas[i];
}

Console.WriteLine("Suma: " + suma);

📺 Salida:

Suma: 224

👀 ¿Viste la magia? El programa recorrió los 5 cajones y fue sumando 0 + 45 + 50 + 38 + 42 + 49 = 224. Funciona igual con 5, 50 o 5 millones de notas. Solo cambias notas, no el código. ✨

🪜 Trazando el for paso a paso

Veamos exactamente qué pasa en cada vuelta del bucle con int[] x = { 10, 20, 30 }; y suma = suma + x[i];:

Vueltaix[i]suma antessuma después
1010010
21201030
32303060

El bucle se detiene cuando i llega a 3, porque 3 < 3 es falso. Por eso nunca toca el cajón x[3] (que no existe). 🛡️

⚠️ Errores comunes al usar for

// ❌ ERROR 1: usar <= en vez de <
for (int i = 0; i <= notas.Length; i++)  // 💥 fuera de rango en la última vuelta
{ ... }

// ✅ CORRECTO
for (int i = 0; i < notas.Length; i++)
{ ... }
// ❌ ERROR 2: olvidar el i++
for (int i = 0; i < notas.Length;)   // bucle infinito 💀
{ ... }

// ✅ CORRECTO
for (int i = 0; i < notas.Length; i++)
{ ... }
// ❌ ERROR 3: usar un número fijo en vez de Length
for (int i = 0; i < 10; i++)   // 💥 si el arreglo tiene 5 elementos, da error
{ ... }

// ✅ CORRECTO: usar Length para que sirva para cualquier tamaño
for (int i = 0; i < notas.Length; i++)
{ ... }

💡 La regla de oro

Cuando recorras un arreglo con for, casi siempre vas a usar esta plantilla:

for (int i = 0; i < miArreglo.Length; i++) { ... }

Memorízala. La vas a usar mucho. 💚

5️⃣ foreach: más simple, menos flexible

⏱️ 20 minutos · 🚀 Una forma más corta de recorrer

🤔 ¿Hay algo más corto?

Cuando solo quieres leer los valores de un arreglo (sin modificar nada, sin usar el índice), existe un bucle especial: el foreach (se lee "for each" → "para cada").

🔁 La sintaxis

// Sintaxis:
// foreach (tipo variable in arreglo)
// {
//     // 'variable' toma el valor de cada cajón, uno por uno
// }

int[] notas = { 45, 50, 38, 42, 49 };

foreach (int n in notas)
{
    Console.WriteLine(n);
}

📺 Salida:

45
50
38
42
49

👀 ¿Qué pasó? La variable n tomó el valor de cada cajón, uno por uno. No tuvimos que manejar índices manualmente. ✨

🆚 for vs foreach

forforeach
¿Necesitas el índice?✅ Sí, lo maneja i❌ No, solo lees el valor
¿Puedes modificar valores?✅ Sí, con arreglo[i] = ...❌ No, solo lectura
¿Más corto de escribir?Un poco más largo✅ Más corto
¿Más seguro?Hay que cuidar Length✅ No hay riesgo de salirse

🎯 Cuándo usar cada uno

🔁

Usa for cuando...

  • Necesitas el índice (i) para algo
  • Quieres cambiar valores del arreglo
  • Recorres solo una parte (ej. desde el cajón 2)
  • Recorres en orden inverso
🔂

Usa foreach cuando...

  • Solo quieres leer los valores
  • No te importa la posición
  • Quieres código más limpio y corto
  • Estás empezando y no necesitas el índice

👀 Ejemplo lado a lado

Para sumar todos los elementos, ambos funcionan:

// Con for
int suma1 = 0;
for (int i = 0; i < notas.Length; i++)
{
    suma1 = suma1 + notas[i];
}

// Con foreach
int suma2 = 0;
foreach (int n in notas)
{
    suma2 = suma2 + n;
}

Para duplicar cada valor, solo for sirve (porque foreach no deja modificar):

// Solo con for puedes hacer esto:
for (int i = 0; i < notas.Length; i++)
{
    notas[i] = notas[i] * 2;   // modifica el arreglo
}

⚠️ Trampa común

En foreach, la variable del bucle (n, x, etc.) es solo una copia del valor. Cambiarla no cambia el arreglo original. Si necesitas modificar el arreglo, usa for siempre.

💡 Tip profesional

Cuando dudes, empieza con foreach (es más limpio). Si después necesitas el índice o modificar, cámbialo a for. No hay problema en mezclar los dos en el mismo programa. 💚

6️⃣ 🧪 Taller: la lista de la clase

⏱️ 40 minutos · 🏗️ Hora de construir con nombres, edades y calificaciones

🎬 El proyecto

La profesora Laura volvió. Esta vez tiene un nuevo problema: quiere un programa que guarde la lista completa de su curso: el nombre de cada estudiante, su edad y su calificación final. Después quiere poder ver la lista bonita, como una tabla. 📒

Vamos a construirlo paso a paso, en tres retos. 💪

🎯 Reto 1: tres arreglos paralelos

La idea: un arreglo por cada tipo de dato. El estudiante en la posición i del arreglo de nombres es el mismo que está en la posición i del arreglo de edades y de calificaciones.

📚 El concepto: arreglos paralelos

0"Ana"
1"Luis"
2"Sofía"
3"Mateo"

nombres[0] = "Ana" → edades[0] = 16 → notas[0] = 4.5

using System;

class ListaClase
{
    public static void Main()
    {
        // 1. Creamos los tres arreglos del mismo tamaño
        string[] nombres = { "Ana", "Luis", "Sofía", "Mateo" };
        int[]    edades   = {   16,    17,      16,      15 };
        double[] notas    = {  4.5,   3.8,     4.9,     2.7 };

        // 2. Mostramos la información en formato tabla
        Console.WriteLine("NOMBRE   EDAD   NOTA");
        Console.WriteLine("-------  -----  -----");

        for (int i = 0; i < nombres.Length; i++)
        {
            Console.WriteLine(nombres[i].PadRight(8) + "  "
                              + edades[i] + "     "
                              + notas[i]);
        }
    }
}

📺 Salida:

NOMBRE   EDAD   NOTA
-------  -----  -----
Ana        16     4.5
Luis       17     3.8
Sofía      16     4.9
Mateo      15     2.7

💡 El método PadRight

"Ana".PadRight(8) rellena con espacios a la derecha hasta completar 8 caracteres. Sirve para alinear columnas en la consola. Es un truco muy útil. ✨

🎯 Reto 2: llenar los arreglos con Console.ReadLine

Ahora vamos a pedirle los datos al usuario. El programa preguntará por cada estudiante y los guardará en los cajones.

using System;

class LlenarLista
{
    public static void Main()
    {
        Console.Write("¿Cuántos estudiantes tiene el curso? ");
        int n = int.Parse(Console.ReadLine());

        // Creamos los arreglos vacíos, pero del tamaño correcto
        string[] nombres = new string[n];
        int[]    edades  = new int[n];
        double[] notas   = new double[n];

        for (int i = 0; i < n; i++)
        {
            Console.WriteLine("\nEstudiante #" + (i + 1));
            Console.Write("  Nombre: ");
            nombres[i] = Console.ReadLine();
            Console.Write("  Edad:   ");
            edades[i] = int.Parse(Console.ReadLine());
            Console.Write("  Nota:   ");
            notas[i] = double.Parse(Console.ReadLine());
        }

        // Mostramos la tabla
        Console.WriteLine("\n=== LISTA DE LA CLASE ===");
        Console.WriteLine("NOMBRE          EDAD   NOTA");
        Console.WriteLine("--------------  -----  -----");
        for (int i = 0; i < n; i++)
        {
            Console.WriteLine(nombres[i].PadRight(15) + "  "
                              + edades[i] + "     "
                              + notas[i]);
        }
    }
}

👀 Mira lo que hicimos

  • 📏 Tamaño dinámico: primero preguntamos cuántos estudiantes hay, y creamos los arreglos de ese tamaño.
  • 🔁 Un solo for: recorremos los tres arreglos a la vez con el mismo índice i.
  • 📝 Llenamos cajón por cajón: en cada vuelta, leemos nombre, edad y nota del mismo estudiante.

🎯 Reto 3: agregar estadísticas

Ahora que tenemos los datos, podemos calcular cosas útiles: el promedio, la nota más alta, cuántos aprobaron...

using System;

class EstadisticasClase
{
    public static void Main()
    {
        string[] nombres = { "Ana", "Luis", "Sofía", "Mateo" };
        double[] notas   = {  4.5,   3.8,    4.9,    2.7  };

        // Promedio
        double suma = 0;
        for (int i = 0; i < notas.Length; i++)
        {
            suma = suma + notas[i];
        }
        double promedio = suma / notas.Length;

        // Nota más alta
        double maxima = notas[0];
        for (int i = 1; i < notas.Length; i++)
        {
            if (notas[i] > maxima) maxima = notas[i];
        }

        // Cuántos aprobaron (nota >= 3.0)
        int aprobados = 0;
        for (int i = 0; i < notas.Length; i++)
        {
            if (notas[i] >= 3.0) aprobados++;
        }

        // Mostramos todo
        Console.WriteLine("=== ESTADÍSTICAS ===");
        Console.WriteLine("Promedio:       " + promedio);
        Console.WriteLine("Nota máxima:    " + maxima);
        Console.WriteLine("Aprobados:      " + aprobados + " de " + notas.Length);
    }
}

📺 Salida esperada:

=== ESTADÍSTICAS ===
Promedio:       3.975
Nota máxima:    4.9
Aprobados:      3 de 4

🏆 Ejercicio 6.3 (Desafío): Construye un programa completo que pida al usuario las notas de 5 estudiantes, calcule el promedio, muestre los que aprobaron y los que no. Todo con tres arreglos paralelos y al menos dos for.

using System;

class ProgramaFinal
{
    public static void Main()
    {
        string[] nombres = new string[5];
        double[] notas   = new double[5];

        // 1. Pedimos los datos
        for (int i = 0; i < 5; i++)
        {
            Console.Write("Nombre del estudiante " + (i + 1) + ": ");
            nombres[i] = Console.ReadLine();
            Console.Write("Nota: ");
            notas[i] = double.Parse(Console.ReadLine());
        }

        // 2. Calculamos el promedio
        double suma = 0;
        for (int i = 0; i < notas.Length; i++) suma += notas[i];
        double promedio = suma / notas.Length;

        // 3. Mostramos aprobados y reprobados
        Console.WriteLine("\nPromedio: " + promedio.ToString("F2"));
        Console.WriteLine("\nAprobados:");
        for (int i = 0; i < notas.Length; i++)
            if (notas[i] >= 3.0)
                Console.WriteLine("  ✅ " + nombres[i] + " (" + notas[i] + ")");

        Console.WriteLine("\nReprobados:");
        for (int i = 0; i < notas.Length; i++)
            if (notas[i] < 3.0)
                Console.WriteLine("  ❌ " + nombres[i] + " (" + notas[i] + ")");
    }
}

7️⃣ Operaciones útiles con arreglos

⏱️ 30 minutos · 🧮 Las cuentas que vas a hacer todo el tiempo

🎯 El poder de los arreglos

Ya sabes crear arreglos, acceder a sus cajones y recorrerlos. Ahora viene la parte donde se vuelven realmente útiles: aplicarles operaciones. En este módulo verás los patrones más comunes. 💪

➕ Sumar todos los elementos

El patrón clásico. Inicias un acumulador en 0 y le vas sumando cada cajón:

int[] nums = { 4, 8, 2, 9, 1 };
int suma = 0;
for (int i = 0; i < nums.Length; i++)
{
    suma = suma + nums[i];   // o: suma += nums[i];
}
Console.WriteLine(suma);   // 24

➗ Calcular el promedio

El promedio es la suma dividida entre la cantidad. Ya tienes la suma del paso anterior, así que es fácil:

double[] notas = { 4.5, 3.8, 4.9, 2.7 };
double suma = 0;
for (int i = 0; i < notas.Length; i++)
{
    suma += notas[i];
}
double promedio = suma / notas.Length;
Console.WriteLine("Promedio: " + promedio);   // 3.975

🔝 Encontrar el valor más alto

Empezamos suponiendo que el primer cajón es el más grande. Después, vamos comparando con los demás y actualizamos si encontramos uno mayor.

int[] nums = { 4, 8, 2, 9, 1 };
int max = nums[0];   // empezamos suponiendo que nums[0] es el mayor
for (int i = 1; i < nums.Length; i++)
{
    if (nums[i] > max)   // si encontramos uno mayor...
    {
        max = nums[i];   // ...lo actualizamos
    }
}
Console.WriteLine("Máximo: " + max);   // 9

🔎 Encontrar el valor más bajo

El mismo patrón, pero con < en vez de >:

int min = nums[0];
for (int i = 1; i < nums.Length; i++)
{
    if (nums[i] < min) min = nums[i];
}
Console.WriteLine("Mínimo: " + min);   // 1

🔍 Buscar un valor

Recorremos el arreglo hasta encontrar lo que buscamos. Si lo hallamos, guardamos su posición:

string[] nombres = { "Ana", "Luis", "Sofía", "Mateo" };
string buscado = "Sofía";

int posicion = -1;   // -1 significa "no lo encontré"
for (int i = 0; i < nombres.Length; i++)
{
    if (nombres[i] == buscado)
    {
        posicion = i;
        break;   // ya lo encontramos, salimos del bucle
    }
}

if (posicion == -1)
    Console.WriteLine("No se encontró a " + buscado);
else
    Console.WriteLine(buscado + " está en la posición " + posicion);

💡 Por qué empezar con -1

Si el valor buscado no está en el arreglo, no se actualiza la variable, que sigue valiendo -1. Como -1 no es un índice válido, nos sirve como "señal" de que no lo encontramos.

🔢 Contar cuántos cumplen una condición

Un contador que solo se incrementa cuando se cumple la condición que nos interesa:

double[] notas = { 4.5, 3.8, 4.9, 2.7, 1.8, 3.0 };
int aprobados = 0;
for (int i = 0; i < notas.Length; i++)
{
    if (notas[i] >= 3.0) aprobados++;
}
Console.WriteLine("Aprobados: " + aprobados);   // 4

📋 El patrón "reportero"

Una operación muy común: recorrer el arreglo y, al final, mostrar un resumen con los resultados de las cuentas anteriores.

using System;

class Reporte
{
    public static void Main()
    {
        double[] notas = { 4.5, 3.8, 4.9, 2.7, 1.8, 3.0 };
        int n = notas.Length;

        double suma = 0, max = notas[0], min = notas[0];
        int aprobados = 0;

        for (int i = 0; i < n; i++)
        {
            suma += notas[i];
            if (notas[i] > max) max = notas[i];
            if (notas[i] < min) min = notas[i];
            if (notas[i] >= 3.0) aprobados++;
        }

        Console.WriteLine("=== REPORTE ===");
        Console.WriteLine("Cantidad:    " + n);
        Console.WriteLine("Suma:        " + suma);
        Console.WriteLine("Promedio:    " + (suma / n).ToString("F2"));
        Console.WriteLine("Máximo:      " + max);
        Console.WriteLine("Mínimo:      " + min);
        Console.WriteLine("Aprobados:   " + aprobados);
    }
}

💡 Truco de eficiencia

Fíjate que en el código de arriba hicimos un solo for para calcular todas las estadísticas. Podrías hacer un bucle por cada cuenta, pero sería menos elegante y más lento. Cuando puedas, recorre una sola vez y haz todas las cuentas ahí mismo. 💚
