1️⃣ ¿Qué es una función?

⏱️ 25 minutos · 📚 La idea más importante del día

🎬 Una analogía de cine

Piensa en una función como una escena de una película:

  • 🎭 Los actores que entran al escenario son los parámetros (los datos que recibe)
  • 📖 La historia que se desarrolla es el código interno
  • 📺 Lo que termina saliendo en pantalla al final es el retorno (el resultado)

Una función es, simplemente, una receta con nombre que puedes usar cada vez que la necesites.

📖 La definición formal (pero amigable)

Una función en C# (también llamada método) es un bloque de código con nombre que:

  • ✅ Hace una sola cosa bien hecha
  • ✅ Puede recibir datos de entrada (parámetros)
  • ✅ Puede devolver un resultado (retorno)
  • ✅ Se puede llamar todas las veces que quieras

🧬 Anatomía de una función en C#

Mira este ejemplo. Cada parte tiene un nombre:

public static int Sumar(int a, int b)
{
    int resultado = a + b;
    return resultado;
}
public static

Modificadores: indican que la función es pública y que se puede usar sin crear un objeto. Por ahora, siempre los pondremos.

int

Tipo de retorno: qué tipo de dato devuelve la función. int = número entero.

Sumar

Nombre: empieza con mayúscula y describe qué hace. Usa verbos en infinitivo.

(int a, int b)

Parámetros: los datos que la función necesita para trabajar.

{ ... }

Cuerpo: el código que se ejecuta cuando llamas a la función.

return

Retorno: devuelve el resultado al lugar donde se llamó la función.

🚀 Tu primera función completa

Lee este programa. Fíjate cómo se llama a la función tres veces:

using System;

class Programa
{
    // Definimos la función
    public static void Saludar()
    {
        Console.WriteLine("¡Hola! Soy una función de C# ⚡");
    }

    public static void Main()
    {
        Saludar();   // Primera llamada
        Saludar();   // Segunda llamada
        Saludar();   // Tercera llamada — ¡mira, sin copiar!
    }
}

📺 Salida en pantalla:

¡Hola! Soy una función de C# ⚡
¡Hola! Soy una función de C# ⚡
¡Hola! Soy una función de C# ⚡

🔑 La palabra void

Cuando una función no devuelve nada, escribimos void en lugar del tipo de retorno. void significa "vacío" en inglés.

  • 📢 void Saludar() → solo hace algo (imprime), no devuelve ningún valor.
  • 📦 int Sumar(...) → devuelve un número entero.

🤔 ¿Por qué son tan útiles?

Imagina que tienes un programa que imprime un saludo en 20 lugares diferentes. Sin funciones, copiarías el Console.WriteLine 20 veces. Si después quieres cambiar el mensaje, tendrías que cambiarlo 20 veces. 😱

Con una función, escribes el código una sola vez y la llamas 20 veces. Si cambias el mensaje, lo cambias en un solo lugar. ¡Magia! ✨

2️⃣ Parámetros: los datos de entrada

⏱️ 30 minutos · 📥 Cómo le pasamos información a una función

🍕 Analogía: la pizzería

Cuando llamas a una pizzería y pides una pizza, necesitas decir:

  • 🍕 El tamaño (¿chica, mediana, grande?)
  • 🧀 Los ingredientes (¿queso, pepperoni, champiñones?)
  • 📍 Tu dirección de entrega

Esos tres datos son los parámetros de la función "HacerPizza". Sin ellos, la pizzería no podría hacer su trabajo.

📥 Una función con un parámetro

Empecemos con lo más simple: una función que recibe un solo dato.

public static void Saludar(string nombre)
{
    Console.WriteLine("¡Hola, " + nombre + "!");
}

public static void Main()
{
    Saludar("Camila");
    Saludar("Juan");
    Saludar("Profe");
}

📺 Salida:

¡Hola, Camila!
¡Hola, Juan!
¡Hola, Profe!

👀 ¿Qué pasó? La función Saludar recibe un texto (string) llamado nombre. Cada vez que la llamamos, el valor que pasamos se guarda en nombre.

📥📥 Varios parámetros a la vez

Una función puede recibir todos los datos que necesite. Para eso, los separamos con comas (,):

public static void Main()
{
    MostrarFicha("Lucía", 16, "Bogotá");
    MostrarFicha("Andrés", 17, "Medellín");

El orden importa mucho. Si cambias el orden de los argumentos, el resultado puede ser completamente distinto:

public static void Restar(int a, int b)
{
    Console.WriteLine(a - b);

Restar(10, 3);   // Imprime 7
Restar(3, 10);   // Imprime -7  ← ¡muy diferente!

🍎 Ejemplo del mundo real: calculadora de IMC

El IMC (Índice de Masa Corporal) nos dice si nuestro peso es saludable. Veamos cómo se calcula con una función:

public static void CalcularIMC(double peso, double altura)
{
    double imc = peso / (altura * altura);
    Console.WriteLine("Tu IMC es: " + imc);

    if (imc < 18.5)
        Console.WriteLine("Categoría: Bajo peso");
    else if (imc < 25)
        Console.WriteLine("Categoría: Peso normal");
    else
        Console.WriteLine("Categoría: Sobrepeso");
}

public static void Main()
{
    CalcularIMC(55.5, 1.65);   // peso en kg, altura en metros
}

3️⃣ Retorno: la respuesta de la función

⏱️ 25 minutos · 📤 Cómo las funciones devuelven resultados

🏧 Analogía: el cajero automático

Cuando usas un cajero:

  • 💳 Metes la tarjeta y tecleas el monto que quieres sacar (esto son los parámetros)
  • ⚙️ El cajero verifica tu saldo, descuenta, prepara los billetes (esto es el código interno)
  • 💵 Te entrega el dinero (esto es el retorno)

El retorno es lo que la función te "entrega" después de hacer su trabajo.

📤 La palabra mágica: return

Para que una función devuelva un valor, usamos la palabra return:

public static int Sumar(int a, int b)
{
    int resultado = a + b;
    return resultado;     // 👈 Devolvemos el valor
}

public static void Main()
{
    int total = Sumar(7, 3);   // total vale 10
    Console.WriteLine(total);   // imprime: 10
}

🔑 Tres reglas de oro del return

  1. Lo que devuelves debe coincidir con el tipo declarado al inicio (int, string, etc.).
  2. Una vez que se ejecuta return, la función termina. Lo que venga después no se ejecuta.
  3. Si la función es void, no puede devolver un valor (puede tener return; solo, opcional).

🎁 Tipos de retorno que vas a usar

Devolver un número:

public static int Cuadrado(int n)
{
    return n * n;
}
// Cuadrado(5)  →  25

Devolver un texto:

public static string ObtenerSaludo(string nombre)
{
    return "¡Hola, " + nombre + "! Bienvenid@ al curso.";
}
// ObtenerSaludo("Ana")  →  "¡Hola, Ana! Bienvenid@ al curso."

Devolver un valor lógico (verdadero o falso):

public static bool EsPar(int numero)
{
    return numero % 2 == 0;
}
// EsPar(4)  →  true
// EsPar(7)  →  false

🔗 Encadenando funciones (¡la parte divertida!)

Lo poderoso del retorno es que puedes usar el resultado de una función como entrada de otra:

public static int Sumar(int a, int b)   { return a + b; }
public static int Doble(int n)          { return n * 2; }

public static void Main()
{
    // Primero Sumar(3, 4) = 7, después Doble(7) = 14
    int x = Doble(Sumar(3, 4));
    Console.WriteLine(x);   // imprime: 14
}

Es como una cadena de montaje: una función le pasa su resultado a la siguiente. 🏭

🚪 Retorno temprano: salir antes de tiempo

A veces queremos salir de la función antes de llegar al final. Por ejemplo, para evitar dividir entre cero:

public static double Dividir(double a, double b)
{
    if (b == 0)
    {
        Console.WriteLine("⚠️ No se puede dividir entre cero");
        return 0;       // Salimos temprano
    }

    return a / b;       // Si b no es cero, hacemos la división
}

4️⃣ Paso por valor vs por referencia

⏱️ 30 minutos · 🚨 El tema que más confunde (¡lo vamos a aclarar!)

📓 Analogía: prestar el cuaderno

Imagina que un amigo te pide tu cuaderno para hacer una tarea. Tienes dos opciones:

  • 📋 Paso por valor: le das una fotocopia. Él puede rayar la fotocopia todo lo que quiera, pero tu cuaderno original queda intacto.
  • 📓 Paso por referencia: le das tu cuaderno original. Si él escribe o borra algo, los cambios quedan en tu cuaderno.

En C# pasa algo similar cuando una función recibe variables.

🟦 Paso por VALOR (lo que pasa por defecto)

Por defecto, C# pasa las variables por valor: hace una copia. La función trabaja con la copia, no con el original.

public static void Duplicar(int numero)
{
    numero = numero * 2;
    Console.WriteLine("Dentro de la función: " + numero);
}

public static void Main()
{
    int x = 5;
    Duplicar(x);
    Console.WriteLine("Fuera de la función: " + x);
}

📺 Salida:

Dentro de la función: 10
Fuera de la función: 5

👀 ¿Lo notaste? Aunque dentro de la función numero se duplicó, la variable x en el Main sigue valiendo 5. La función solo modificó su copia.

🟪 Paso por REFERENCIA (usando ref)

Si queremos que la función modifique la variable original, usamos la palabra ref. Hay que ponerla en dos lugares:

public static void Duplicar(ref int numero)   // 👈 ref aquí
{
    numero = numero * 2;
}

public static void Main()
{
    int x = 5;
    Duplicar(ref x);   // 👈 ref también aquí
    Console.WriteLine("x ahora vale: " + x);
}

📺 Salida:

x ahora vale: 10

🎉 ¡Ahora sí! La variable original cambió. Le dimos el cuaderno original, no una fotocopia.

⚠️ Detalle importante de ref

Cuando usas ref, la variable debe estar inicializada antes de llamar a la función. No puede valer null (en el caso de los tipos por referencia).

🟧 La palabra out (devolver varios valores)

Hay un caso especial: cuando una función quiere devolver varios valores a la vez. Para eso existe out.

La diferencia con ref:

  • ref → la variable ya tiene un valor al entrar, y puede salir modificada.
  • out → la variable no necesita tener valor al entrar, pero la función está obligada a asignarle uno antes de terminar.
public static void Dividir(int a, int b, out int cociente, out int residuo)
{
    cociente = a / b;
    residuo  = a % b;
}

public static void Main()
{
    int c, r;                    // No es necesario inicializar
    Dividir(17, 5, out c, out r);
    Console.WriteLine($"Cociente: {c}, Residuo: {r}");
}

📺 Salida:

Cociente: 3, Residuo: 2

🔁 Ejemplo clásico: intercambiar dos variables

Un problema muy común: tienes dos variables y quieres intercambiar sus valores. ¡ref al rescate!

public static void Intercambiar(ref int x, ref int y)
{
    int temp = x;
    x = y;
    y = temp;
}

public static void Main()
{
    int a = 100, b = 200;
    Console.WriteLine($"Antes: a={a}, b={b}");

    Intercambiar(ref a, ref b);

    Console.WriteLine($"Después: a={a}, b={b}");
}

📺 Salida:

Antes: a=100, b=200
Después: a=200, b=100

🧪 Reto 2: Geometría (áreas y perímetros)

Área de un círculo:

public static double AreaCirculo(double radio)
{
    return Math.PI * radio * radio;
}
// AreaCirculo(5)  →  78.54

Perímetro de un rectángulo:

public static double PerimetroRectangulo(double ancho, double alto)
{
    return 2 * (ancho + alto);
}
// PerimetroRectangulo(4, 3)  →  14

Hipotenusa (teorema de Pitágoras):

public static double Hipotenusa(double catetoA, double catetoB)
{
    double sumaCuadrados = (catetoA * catetoA) + (catetoB * catetoB);
    return Math.Sqrt(sumaCuadrados);   // Math.Sqrt = raíz cuadrada
}
// Hipotenusa(3, 4)  →  5

💡 Tu aliada: la clase Math

C# ya trae una caja de herramientas matemáticas lista para usar:

  • Math.Sqrt(x) → raíz cuadrada de x
  • Math.Pow(x, y) → x elevado a la y
  • Math.Abs(x) → valor absoluto (sin signo)
  • Math.PI → el valor de π (3.14159...)
  • Math.Max(a, b) → el mayor de dos números
  • Math.Min(a, b) → el menor de dos números

🧪 Reto 3: Estadística

Promedio de tres notas:

public static double Promedio(double n1, double n2, double n3)

    return (n1 + n2 + n3) / 3;

// Promedio(4.0, 3.5, 4.8)  →  4.1

Porcentaje:

public static double Porcentaje(double parte, double total)
{
    return (parte / total) * 100;

// Porcentaje(15, 50)  →  30  (15 es el 30% de 50)

Factorial (un clásico):

public static long Factorial(int n)
{
    long resultado = 1;
    for (int i = 2; i <= n; i++)
    {
        resultado = resultado * i;
    }
    return resultado;
}
// Factorial(5)  →  120  (porque 1×2×3×4×5 = 120)

🏆 PROYECTO INTEGRADOR: Calculadora multifunción

Combina todo lo que aprendiste en un solo programa. Léelo con calma y trata de entender cada parte:

using System;

class Calculadora
{
    public static double Sumar(double a, double b)       => a + b;
    public static double Restar(double a, double b)      => a - b;
    public static double Multiplicar(double a, double b) => a * b;
    public static double Dividir(double a, double b)
    {
        if (b == 0) return 0;
        return a / b;
    }
    public static double Potencia(double baseN, double exp) => Math.Pow(baseN, exp);
    public static double Raiz(double n) => Math.Sqrt(n);

    public static void MostrarMenu()
    {
        Console.WriteLine("=== CALCULADORA ===");
        Console.WriteLine("1. Sumar");
        Console.WriteLine("2. Restar");
        Console.WriteLine("3. Multiplicar");
        Console.WriteLine("4. Dividir");
        Console.WriteLine("5. Potencia");
        Console.WriteLine("6. Raíz cuadrada");
        Console.WriteLine("0. Salir");
    }

    public static void Main()
    {
        int opcion;
        do
        {
            MostrarMenu();
            Console.Write("Elige una opción: ");
            opcion = int.Parse(Console.ReadLine());

            if (opcion == 0) break;

            Console.Write("Primer número: ");
            double a = double.Parse(Console.ReadLine());

            double b = 0;
            if (opcion != 6)
            {
                Console.Write("Segundo número: ");
                b = double.Parse(Console.ReadLine());
            }

            double resultado = 0;
            switch (opcion)
            {
                case 1: resultado = Sumar(a, b); break;
                case 2: resultado = Restar(a, b); break;
                case 3: resultado = Multiplicar(a, b); break;
                case 4: resultado = Dividir(a, b); break;
                case 5: resultado = Potencia(a, b); break;
                case 6: resultado = Raiz(a); break;
            }
            Console.WriteLine("Resultado: " + resultado + "\n");
        }
        while (opcion != 0);

        Console.WriteLine("¡Hasta luego! 👋");
    }
}

💡 Sintaxis nueva: =>

La flecha => es una forma compacta de escribir funciones de una sola línea:

public static double Sumar(double a, double b) => a + b;

Es equivalente a:

public static double Sumar(double a, double b)
{
    return a + b;
}

Misma cosa, menos texto. Úsala cuando la función sea muy cortita.

🎯 Desafíos extra (opcionales)

Desafío 5.1: Crea EsPrimo(int n) que devuelva true si n es un número primo.

💡 Pista: un número primo solo es divisible por 1 y por sí mismo. Prueba dividirlo por todos los números entre 2 y n-1. Si alguno divide exacto, no es primo.

public static bool EsPrimo(int n)
{
    if (n < 2) return false;
    for (int i = 2; i < n; i++)
    {
        if (n % i == 0) return false;
    }
    return true;
}

Desafío 5.2: Crea CelsiusAFahrenheit(double c). Fórmula: F = (C × 9/5) + 32.

public static double CelsiusAFahrenheit(double c)
{
    return (c * 9.0 / 5.0) + 32;
}
// CelsiusAFahrenheit(25)  →  77

7️⃣ 🧩 Algoritmos modulares: divide y vencerás

⏱️ 30 minutos · 🏗️ La habilidad más importante de un programador

🧠 La idea más importante del día

En vez de escribir un programa gigante y enmarañado, lo partes en muchas funciones pequeñas que hacen una sola cosa. Los grandes programadores no escriben código complicado: escriben código simple conectado con otros códigos simples.

Las ventajas:

  • 🧠 Fácil de entender: cada función cabe en tu cabeza
  • 🔧 Fácil de arreglar: si algo falla, sabes dónde buscar
  • ♻️ Fácil de reutilizar: la usas en otros programas
  • 🤝 Fácil de trabajar en equipo: cada persona hace una función

🎯 La regla de oro

Una función = una responsabilidad.

Si tu función "hace muchas cosas", probablemente deberías dividirla en varias. Si puedes explicar lo que hace la función en una sola frase corta, vas por buen camino.

👀 Monolítico vs Modular: la comparación

❌ Mal ejemplo (todo metido en el Main):

public static void Main()
{
    Console.Write("Nota 1: ");
    double n1 = double.Parse(Console.ReadLine());
    Console.Write("Nota 2: ");
    double n2 = double.Parse(Console.ReadLine());
    Console.Write("Nota 3: ");
    double n3 = double.Parse(Console.ReadLine());

    double prom = (n1 + n2 + n3) / 3;
    Console.WriteLine("Promedio: " + prom);

    if (prom >= 3.0)
        Console.WriteLine("APROBADO ✅");
    else
        Console.WriteLine("REPROBADO ❌");
}

✅ Buen ejemplo (modular):

public static double LeerNota(string mensaje)
{
    Console.Write(mensaje);
    return double.Parse(Console.ReadLine());
}

public static double CalcularPromedio(double n1, double n2, double n3)
{
    return (n1 + n2 + n3) / 3;
}

public static string Resultado(double promedio)
{
    return promedio >= 3.0 ? "APROBADO ✅" : "REPROBADO ❌";
}

public static void Main()
{
    double n1 = LeerNota("Nota 1: ");
    double n2 = LeerNota("Nota 2: ");
    double n3 = LeerNota("Nota 3: ");

    double prom = CalcularPromedio(n1, n2, n3);
    Console.WriteLine("Promedio: " + prom);
    Console.WriteLine(Resultado(prom));
}

👀 ¿Ves la diferencia? El segundo código se lee casi como una receta: lee, lee, lee, calcula, muestra, muestra. Cada paso tiene un nombre claro.

🏆 PROYECTO INTEGRADOR: Sistema de notas escolares

Construyamos un sistema completo. Léelo y trata de identificar las "responsabilidades":

using System;

class SistemaNotas
{
    // ---- ENTRADA ----
    public static double LeerNota(string materia)
    {
        Console.Write($"Ingresa la nota de {materia} (0-5): ");
        return double.Parse(Console.ReadLine());
    }

    // ---- CÁLCULOS ----
    public static double CalcularPromedio(double n1, double n2, double n3, double n4)
    {
        return (n1 + n2 + n3 + n4) / 4;
    }

    public static double CalcularMaxima(double n1, double n2, double n3, double n4)
    {
        double max = n1;
        if (n2 > max) max = n2;
        if (n3 > max) max = n3;
        if (n4 > max) max = n4;
        return max;
    }

    public static double CalcularMinima(double n1, double n2, double n3, double n4)
    {
        double min = n1;
        if (n2 < min) min = n2;
        if (n3 < min) min = n3;
        if (n4 < min) min = n4;
        return min;
    }

    // ---- DECISIÓN ----
    public static string EstadoEstudiante(double promedio)
    {
        if (promedio >= 4.5) return "🌟 EXCELENTE";
        if (promedio >= 4.0) return "🎉 SOBRESALIENTE";
        if (promedio >= 3.0) return "👍 APROBADO";
        return "📚 NECESITA REFUERZO";
    }

    // ---- SALIDA ----
    public static void MostrarReporte(string nombre, double prom,
                                      double max, double min, string estado)
    {
        Console.WriteLine("\n=== REPORTE DE " + nombre.ToUpper() + " ===");
        Console.WriteLine($"Promedio:    {prom:F2}");
        Console.WriteLine($"Nota máxima: {max:F2}");
        Console.WriteLine($"Nota mínima: {min:F2}");
        Console.WriteLine($"Estado:      {estado}");
        Console.WriteLine("=============================");
    }

    // ---- PROGRAMA PRINCIPAL ----
    public static void Main()
    {
        Console.Write("Nombre del estudiante: ");
        string nombre = Console.ReadLine();

        double mate = LeerNota("Matemáticas");
        double esp  = LeerNota("Español");
        double cien = LeerNota("Ciencias");
        double soc  = LeerNota("Sociales");

        double prom = CalcularPromedio(mate, esp, cien, soc);
        double max  = CalcularMaxima(mate, esp, cien, soc);
        double min  = CalcularMinima(mate, esp, cien, soc);
        string est  = EstadoEstudiante(prom);

        MostrarReporte(nombre, prom, max, min, est);
    }
}

💡 ¿Notaste el patrón?

Las funciones están agrupadas por responsabilidad:

  • 📥 Entrada (LeerNota): recoge datos del usuario
  • 🧮 Cálculo (CalcularPromedio, CalcularMaxima, CalcularMinima): hace las cuentas
  • 🤔 Decisión (EstadoEstudiante): toma decisiones según los datos
  • 📺 Salida (MostrarReporte): muestra los resultados

Este patrón se llama Entrada-Proceso-Salida (a veces abreviado E-P-S) y es la base de casi todos los programas que vas a escribir en tu vida. Grábatelo en la memoria. 🧠

🚀 Tu desafío integrador

🏗️ Construye un convertidor de unidades modular.

El programa debe tener estas funciones (todas public static double):

  • MetrosAPies(double m) → 1 metro = 3.281 pies
  • KilosALibras(double kg) → 1 kg = 2.205 libras
  • CelsiusAFahrenheit(double c) → (c × 9/5) + 32
  • MostrarMenu() → muestra las opciones al usuario
  • Main() → usa un bucle para repetir hasta que el usuario quiera salir

💡 Pista profesional: usa la sintaxis => para las funciones de una línea.

using System;

class Convertidor
{
    public static double MetrosAPies(double m)         => m * 3.281;
    public static double KilosALibras(double kg)       => kg * 2.205;
    public static double CelsiusAFahrenheit(double c)  => (c * 9.0 / 5.0) + 32;

    public static void MostrarMenu()
    {
        Console.WriteLine("\n=== CONVERTIDOR ===");
        Console.WriteLine("1. Metros → Pies");
        Console.WriteLine("2. Kilos → Libras");
        Console.WriteLine("3. Celsius → Fahrenheit");
        Console.WriteLine("0. Salir");
    }

    public static void Main()
    {
        int op;
        do
        {
            MostrarMenu();
            Console.Write("Opción: ");
            op = int.Parse(Console.ReadLine());
            if (op == 0) break;

            Console.Write("Valor a convertir: ");
            double v = double.Parse(Console.ReadLine());

            switch (op)
            {
                case 1: Console.WriteLine(MetrosAPies(v) + " pies"); break;
                case 2: Console.WriteLine(KilosALibras(v) + " libras"); break;
                case 3: Console.WriteLine(CelsiusAFahrenheit(v) + " °F"); break;
                default: Console.WriteLine("Opción inválida"); break;
            }
        }
        while (op != 0);

        Console.WriteLine("¡Adiós! 👋");
    }
}
